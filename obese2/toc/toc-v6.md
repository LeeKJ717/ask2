## 0. 이 책의 설계 원리

**목적.** 비만치료약물이 몸 안에서 작용하는 방식을 생리학, 세포학, 분자생물학, 유전학, 단백질학으로 풀어 쓴 뒤, 같은 지식으로 독자가 새 약물 후보를 찾는 연구를 설계하고 직접 수행하게 한다. 책 한 권(두 권 한 벌)만으로 문헌 수집, 표적 선정, 신호 모델링, 구조 계산, 후보 설계, 실험 검증 계획까지 닿는다.

**3권 구성.** 한 주제를 세 권으로 나눈다. 쪽수 제한은 두지 않고 이해에 필요한 만큼 서술한다.

| 권 | 이름(가제) | 구성 | 독자 |
|---|---|---|---|
| 1권 | 비만치료약물의 생리학과 신호전달 (원리편) | 1~5부, 1~17장 | 약이 왜, 어떻게 듣는가 |
| 2권 | 세포에너지대사학 | 별도 목차 vol2-toc-v1.md(9부 42장, 식후 대사 에너지 5부, 공복 대사 에너지 6부) | 대사 배경을 처음부터 체계적으로 |
| 3권 | 비만치료약물 신약 설계 (실무편) | 1~4부, 1~13장 | 직접 연구하려는 사람 |

1권은 약물의 작용을, 2권은 그 밑바탕인 세포의 에너지 대사를, 3권은 오픈 데이터·오픈소스·로컬 GPU로 하는 신약 설계 연구를 다룬다. 2권은 1권 8·9장이 기대는 배경(해당, TCA 회로, 전자전달계, 지방산 산화, 케톤체, AMPK/mTOR)을 상세히 맡고, 1권 9장은 그 요약과 연결 장으로 줄인다. 3권은 1권의 지도(회로, 신호 경로, 표적 후보, 약물 한계)를 입력으로 쓰므로 3권 앞에서 이를 요약해 다시 제시한다. 3권만 펴도 따라올 수 있다.

**자체완결성을 만드는 장치.** 앞 장의 산출물이 뒤 장의 입력이 된다.

| 단계 | 장 | 독자가 손에 쥐는 산출물 | 다음에 쓰이는 곳 |
|---|---|---|---|
| 1 | 1권 3~5장 | 에너지 항상성 회로도(호르몬-뇌-장기) | 1권 6장, 3권 2장 |
| 2 | 1권 6~9장 | 수용체에서 유전자 발현까지의 신호 지도(경로, 분자, 속도 상수 목록) | 3권 10장 모델 |
| 3 | 1권 10~12장 | 유전학과 구조 근거로 점수화한 표적 후보표 | 3권 2장, 11장 |
| 4 | 1권 13~17장 | 기존 약물 비교표와 미충족 요구 목록 | 3권 1장 목표 설정 |
| 5 | 3권 1~3장 | 연구 계획서 틀, 표적 우선순위, 검증 설계 원칙 | 3권 4~11장 |
| 6 | 3권 4~9장 | 로컬 GPU 환경, 데이터 사본, 도구 사용법, 재현 가능한 작업 흐름 | 3권 10~11장 |
| 7 | 3권 10~11장 | 구현 사례 2건의 입력, 코드, 출력, 판정 | 독자의 연구 |
| 8 | 3권 12~13장 | 약물 밖 신호, 특허·규제·임상 경로 | 독자의 연구 |

**각 장의 틀(공통).**
1. 장 도입: 그 개념이 과학사에서 어떤 상황에서 발견되었는지를 이야기로 서술(인물, 시대 배경, 실패와 전환점)
2. 핵심 개념: 새 용어는 처음 나올 때 정식 전체 명칭(full name)으로 표기
3. 핵심 논문 해부: 실험 배경 → 과정 → 결과 → 해석(근거 논문은 obesepharma_db에서 고르고 서지는 Crossref로 대조)
4. 그림과 표: 모든 그림과 표에 번호와 제목(그림 3-2, 표 3-2). 표는 한 쪽 안에 배치
5. 생물 그림 규칙: 개체 → 조직 → 세포 → 세포소기관 → 핵 → 염색체 → 유전자 → mRNA → 리보솜 순서의 구체적 그림을 넣어 추상적 설명을 막는다. 교과서식 도해(지시선 라벨, 정상 대 병변 대비, 경로 도식, 분자 수준 결합 표시)
6. 3권의 장은 **실습 상자**를 둔다: 목표 → 입력 → 도구 → 명령 → 출력 → 판정 기준 → 흔한 실패
7. 장 끝: 요약, 다음 장으로 넘기는 산출물, APA 7판 참고문헌(본문보다 1pt 작고 줄간격 좁게)

**표기 원칙.** 한자어 용어는 한국어 발음으로 적는다(중국어 병음 사용 안 함). 약어는 처음에 전체 명칭과 함께 쓴다.

## 제1부 출발점

### 1장 비만이라는 병과 약물의 실패사
- 1절 에너지 수지와 지방조직: 비만 정의(체질량지수), 합병증(2형 당뇨병, 고혈압, 대사이상 관련 지방간질환, 수면무호흡)
- 2절 초기 약물의 이야기: 1930년대 대사 촉진제, 암페타민 계열, 1960년대 유럽의 아미노렉스 사건
- 3절 펜플루라민-펜터민 사건: 판막 질환 보고(Connolly 등, 1997)와 5-HT2B 수용체 기전(Rothman 등, 2000) — 작용 선택성이 왜 생사를 가르는가
- 4절 시부트라민, 리모나반트, 로카세린: 심혈관 결과 시험(James 등, 2010), 정신과 이상반응 메타분석(Christensen 등, 2007), 암 신호와 시장 철수(Bohula 등, 2018)
- 5절 렙틴의 발견(Zhang 등, 1994)과 기대의 좌절: 렙틴 저항
- 6절 실패의 공통 원인: 선택성 부족, 말초와 중추의 혼재, 장기 안전성 자료 부족 → 이후 인크레틴으로 가는 필연
- 표 1-1 과거 비만약의 작용점, 효과, 퇴출 사유 / 그림 1-1 비만약물 역사 연표 / 그림 1-2 5-HT2B 판막 기전 도해
- DB 연결: clinical_trials, safety_adverse

### 2장 인크레틴의 발견에서 위고비까지
- 1절 장이 보낸 편지: 세크레틴(1902)에서 인크레틴 개념까지
- 2절 입으로 먹은 포도당이 더 센 인슐린을 부른다: Elrick 등(1964)의 실험과 인크레틴 효과
- 3절 프로글루카곤 유전자(Bell 등, 1983)와 GLP-1(7-36)의 정체(Drucker 등, 1987; Kreymann 등, 1987)
- 4절 도마뱀 독에서 약으로: 엑센딘-4(Eng 등, 1992)와 엑세나타이드
- 5절 걸림돌 디펩티딜 펩티데이스-4와 반감기: 지방산 결합이라는 해법(리라글루타이드), Aib 치환과 알부민 결합(세마글루타이드; Lau 등, 2015)
- 6절 당뇨병약에서 비만약으로: 리라글루타이드 3.0 mg(Pi-Sunyer 등, 2015), 세마글루타이드 2.4 mg(STEP 1; Wilding 등, 2021), 티르제파타이드(Coskun 등, 2018; SURMOUNT-1, Jastreboff 등, 2022)
- 표 2-1 주요 임상시험 요약 / 그림 2-1 발견 연표 / 그림 2-2 약물 계보도(분자 구조 변화)
- DB 연결: physiology, clinical_trials, clinical_named

## 제2부 생리학: 몸 전체에서

### 3장 에너지 항상성의 뇌: 시상하부, 뇌간, 보상회로
- 2권 연결: 공복 때 시상하부가 받는 신호(렙틴 감소, 그렐린 증가)는 2권 27장, 식후와 공복의 전환은 29장
- 궁상핵의 두 뉴런(POMC/CART 대 AgRP/NPY), 실방핵, 뇌간 고립로핵과 최후야, 도파민 보상회로
- 미주신경 구심로와 장-뇌 연결
- 그림 3-1 시상하부 회로도 / 그림 3-2 뇌간-시상하부 신호 흐름 / 표 3-1 뉴런 집단별 신경펩타이드와 기능
- DB 연결: physiology, hypothalamic_targets

### 4장 몸이 보내는 신호: 장·췌장·지방의 호르몬 지도
- 2권 연결: 호르몬 작용 기전은 2권 15장, 식후 인크레틴 효과는 19장
- GLP-1, GIP, 펩타이드 YY, 콜레시스토키닌, 그렐린, 옥신토모듈린, 아밀린, 렙틴, 인슐린의 분비 세포, 시간 곡선, 수용체, 반감기
- 위 배출 지연, 포만, 식후 호르몬 곡선
- 그림 4-1 분비 세포 위치 / 그림 4-2 식후 혈중 농도 곡선 / 표 4-1 호르몬 요약
- DB 연결: physiology, receptor_pharmacology

### 5장 표적 장기: 췌장, 지방, 간, 근육, 신장, 심장
- 2권 연결: 간 31장, 근육 32장, 지방조직 33장, 뇌와 β세포 34장
- 췌도 α·β·δ 세포, 백색·갈색·베이지 지방, 지방간, 근육량 보존 문제, 신장과 심혈관 이득
- 그림 5-1 장기별 약물 효과 지도 / 표 5-1 장기별 근거 수준
- DB 연결: organ_effects

**2부 점검:** 호르몬-회로-장기 지도 완성(산출물 1)

## 제3부 세포학과 신호전달

### 6장 수용체의 세포학: B군 G단백질 연결 수용체와 세포막
- GLP1R, GIPR, GCGR, 아밀린 수용체(칼시토닌 수용체와 RAMP), 활성화 때의 구조 변화
- Gs, Gq, Gi 선택성, β-아레스틴, 내재화와 재순환, 엔도솜 신호
- 편향 작용(biased agonism)의 정의와 정량 방법의 개요
- 그림 6-1 수용체 세포 내 이동 경로 / 그림 6-2 편향 작용 모식도 / 표 6-1 수용체별 G단백질 결합 프로파일
- DB 연결: receptor_pharmacology, cell_signaling, structure_gpcr

### 7장 cAMP에서 인슐린 분비까지: 신호의 하류
- 2권 연결: 식후 인슐린 분비 곡선은 2권 19장, 포도당 의존성의 대사적 근거는 21장
- cAMP 미세영역, PKA, EPAC2, 칼슘, ATP 민감성 칼륨 채널, 인슐린 과립 분비
- 포도당 의존성의 분자 근거(저혈당 위험이 낮은 이유)
- 그림 7-1 β세포 신호 지도 / 그림 7-2 시간 척도별 신호 단계 / 표 7-1 분자별 역할과 억제제
- DB 연결: cell_signaling, cytology, biochemistry

### 8장 뉴런 안의 신호: 렙틴, 멜라노코르틴, AMPK, mTOR
- 2권 연결: AMPK, mTOR, 시르투인의 에너지 감지는 2권 14장, 공복 신호와 오토파지는 28장
- 렙틴 수용체-JAK2-STAT3, PI3K-Akt, AMPK와 mTOR의 에너지 감지, MC4R 신호
- 약물이 뉴런 신호에 합류하는 지점
- 그림 8-1 뉴런 신호 통합도 / 표 8-1 경로별 약물 개입 지점
- DB 연결: hypothalamic_targets, cell_signaling

### 9장 에너지 기관과 스트레스: 미토콘드리아, 소포체, 오토파지 (2권 연결 장)
- 이 장은 요약과 연결 장이다. 해당·TCA·전자전달계·지방산 산화 등 대사 상세는 2권에서 다룬다.
- 지방분해 효소, 갈색지방 UCP1, 소포체 스트레스와 β세포 생존, 오토파지
- 그림 9-1 소기관과 약물 효과 / 표 9-1 스트레스 경로 지표
- DB 연결: cytology, biochemistry

**3부 점검:** 수용체에서 유전자 발현까지의 신호 지도(산출물 2). 3권 10장 모델의 뼈대가 된다.

## 제4부 분자생물학, 유전학, 단백질학

### 10장 유전자 발현과 후성유전
- 전사인자 CREB, PDX1과 표적 유전자, 약물 처리 전사체, 단일세포 지도, DNA 메틸화
- 개체 → 조직 → 세포 → 핵 → 염색체 → 유전자 → mRNA 순서의 그림
- 그림 10-1 개체에서 mRNA까지 / 그림 10-2 단일세포 지도 / 표 10-1 발현 변화 유전자
- DB 연결: genetics, cell_signaling

### 11장 인간 유전학이 가리킨 표적
- 단일유전자 비만(LEP, LEPR, POMC, PCSK1, MC4R), 전장 유전체 연관 연구, 멘델 무작위화
- 약물 반응 유전체학: 현재 근거와 한계(과대 해석 금지)
- 그림 11-1 유전학 근거 사슬 / 표 11-1 유전자별 표적 근거 점수
- DB 연결: genetics

### 12장 단백질화학과 구조: 펩타이드 설계와 결합 포켓
- 아미노산 치환, 지방산 측쇄와 알부민 결합, 반감기 설계, 경구 흡수 보조제
- 극저온 전자현미경 구조가 보여준 결합, 소분자 알로스테릭 결합 포켓
- 그림 12-1 펩타이드 설계 요소 / 그림 12-2 수용체-리간드 결합 구조 / 표 12-1 약물별 구조 특징
- DB 연결: proteomics_structure, structure_gpcr, biochemistry

**4부 점검:** 표적 후보표(산출물 3)

## 제1부 신약 연구의 설계

### 1장 신약 연구의 단계와 의사결정
- 표적 확인 → 히트 → 리드 → 전임상 → 임상 단계와 각 단계의 통과·중단 기준
- 연구 계획서 작성법: 가설, 목표 제품 프로파일, 성공 기준, 중단 기준
- 한국과 국제 규제의 큰 틀(식품의약품안전처, FDA, EMA)
- 그림 1-1 신약 개발 깔때기 / 표 1-1 단계별 산출물과 판정 기준

### 2장 표적 발굴과 우선순위
- 표적 점수화 틀: 유전학 근거 + 발현 위치 + 구조 가용성 + 안전성 신호 + 경쟁 약물 현황
- 공개 전사체와 단일세포 자료 재분석, 유전체 연관 요약통계 기반 공동 국소화와 멘델 무작위화
- 실습 상자: 점수표 만들기, 단일세포 분석 흐름, 요약통계 분석 흐름
- 표 2-1 표적 점수표 예시(GLP1R, GIPR, GCGR, MC4R, GFRAL, 아밀린 수용체 등)

### 3장 실험 검증의 설계와 통계
- 세포 기반 시험(cAMP, β-아레스틴, 인슐린 분비), 동물 모델, 용량-반응, 대조군 설계
- 검정력 분석, 다중비교 보정, 재현성 관리
- 표 3-1 시험 패널과 기대 곡선 / 표 3-2 표본 수 산정 예

**1부 점검:** 연구 계획서 틀, 표적 우선순위, 검증 설계 원칙(산출물 5)

## 제2부 오픈 데이터, 오픈소스, 로컬 GPU 도구상자

이 부 전체가 도구 사용법이다. 각 장은 "무엇인가 → 왜 필요한가 → 설치/접속 → 최소 예제 → 흔한 실패 → 라이선스 주의" 순서로 쓴다.

### 4장 로컬 GPU 연구 환경 만들기
- 1절 GPU가 필요한 계산과 필요 없는 계산: 도킹, 분자동역학, 구조 예측, 생성모델, 언어모델은 GPU, 통계와 데이터 정리는 CPU
- 2절 VRAM 12GB·16GB가 정하는 작업 규모: 분자동역학 시스템 크기, 도킹 배치 크기, 모델 크기와 정밀도(양자화)
- 3절 운영체제와 드라이버: Linux 우선, CUDA 구성, 컨테이너(Docker, Apptainer)와 환경 관리(conda, mamba)
- 4절 장비 배치 전략: 장비별 역할 분담, 작업 대기열, 야간 실행, 장애 복구
- 5절 실측하기: 같은 시험 계산을 장비마다 돌려 표로 기록하는 방법
- 표 4-1 장비별 GPU와 권장 작업 / 표 4-2 실측 결과 기록 양식 / 그림 4-1 작업 흐름과 장비 연결
- 실습 상자: 드라이버 확인, 컨테이너 시험, 벤치마크 스크립트

### 5장 오픈 데이터 지도
- 구조: RCSB PDB, AlphaFold DB, GPCRdb
- 서열·기능: UniProt, Reactome, IUPHAR/BPS Guide to Pharmacology
- 화합물·활성: ChEMBL, BindingDB, PubChem
- 유전·발현: GWAS Catalog, GTEx, Open Targets, GEO, CELLxGENE
- 임상·안전성: ClinicalTrials.gov, openFDA, 의약품 이상반응 보고 자료
- 문헌: PubMed, Europe PMC, obesepharma_db(본 책 수집본)
- 각 자료마다 접속 방법, 내려받기 형식, 로컬 데이터베이스화, 인용 방법, 라이선스
- 표 5-1 자료원 한눈에 보기 / 그림 5-1 로컬 데이터 저장소 구조
- 실습 상자: 서열 내려받기, 활성 자료 추출, 구조 파일 정리

### 6장 오픈소스 I: 구조, 도킹, 분자동역학
- 구조 확보와 예측: ColabFold/LocalColabFold, OpenFold, Boltz, Chai-1, Foldseek, MMseqs2, PyMOL, UCSF ChimeraX
- 도킹: AutoDock Vina, AutoDock-GPU, Uni-Dock, GNINA, DiffDock
- 분자동역학: OpenMM, GROMACS, CHARMM-GUI(웹), OpenFE, OpenFF, MDAnalysis, PLUMED
- 막단백질 시스템 구성: 지질 이중층, 용매, 이온, 평형화 단계
- 표 6-1 도구별 입력·출력·GPU 요구 / 그림 6-1 구조 기반 계산 파이프라인
- 실습 상자: 수용체 구조 준비, 도킹 한 번, 짧은 분자동역학 한 번

### 7장 오픈소스 II: 화학정보, AI 설계, 신호 모델링
- 화학정보: RDKit, Open Babel
- 예측과 설계: DeepChem, Chemprop, ADMET-AI, AiZynthFinder, REINVENT 4
- 단백질·펩타이드 설계: RFdiffusion, ProteinMPNN, BindCraft
- 신호 모델링: COPASI, tellurium(Antimony), BioNetGen, Virtual Cell, JAX/PyTorch 기반 미분방정식
- 표 7-1 도구별 용도와 GPU 요구 / 그림 7-1 설계에서 선별까지의 깔때기
- 실습 상자: 분자 표현과 성질 계산, 간단한 활성 예측, 미분방정식 모델 한 개

### 8장 로컬 언어모델과 문헌 DB 활용
- 1절 obesepharma_db 구조: 논문, 전문, PDF, 검색 이력 표와 질의 예시
- 2절 로컬 언어모델 서비스(Ollama, vLLM)와 임베딩 모델 선택
- 3절 검색 증강 생성(RAG): 쪼개기, 색인, 근거 문장 찾기, 인용 자동 검증
- 4절 환각을 막는 절차: 인용 서지를 DOI로 대조하는 습관
- 표 8-1 모델 크기별 VRAM 요구 / 그림 8-1 문헌 질의응답 흐름
- 실습 상자: 색인 만들기, 질문하고 근거 문장 확인하기

### 9장 재현 가능한 연구 흐름
- 작업 흐름 도구(Snakemake, Nextflow), 버전 관리(git), 컨테이너 고정, 난수 시드, 입력 해시
- 결과 기록: 실행 이력 표, 로그 규칙, 결과 파일 이름 규칙
- 표 9-1 재현성 점검표 / 그림 9-1 저장소 구조
- 실습 상자: 작은 파이프라인 한 개를 재현 가능하게 만들기

**2부 점검:** 데이터 사본, 환경, 도구 사용법, 재현 흐름 준비 완료(산출물 6)

## 제3부 구현 사례

### 10장 사례 1: GLP-1 수용체 신호 모델과 편향 작용제 정량
- 목표: 서로 다른 작용제가 같은 수용체에서 cAMP 신호와 β-아레스틴 신호를 다르게 일으키는 정도를 수치(편향 계수)로 비교하고, 신호 모델로 세포 반응을 예측한다
- 1절 문제 정의와 가설
- 2절 입력 자료: 공개 활성 자료(ChEMBL, IUPHAR)와 논문 속 용량-반응 곡선에서 추출한 값
- 3절 작용 모형(operational model)으로 효능과 친화도를 분리, 편향 계수 계산
- 4절 GLP1R-Gs-cAMP-PKA 경로 상미분방정식 모델 구성(1권 3부 신호 지도 사용)
- 5절 매개변수 추정, 민감도 분석, GPU로 많은 매개변수 조합 동시 탐색
- 6절 해석: 편향이 곧 체중 감소나 부작용 차이로 번역되는가에 대한 한계 논의
- 7절 이 사례를 자기 연구로 바꾸는 법
- 입력 파일, 코드, 출력 그림·표, 판정 기준을 모두 수록

### 11장 사례 2: 구조 기반 소분자 작용제 후보 탐색
- 목표: B군 수용체의 소분자 결합 포켓을 대상으로 후보를 가상 스크리닝하고, 분자동역학으로 재평가해 우선순위를 만든다
- 1절 문제 정의: 펩타이드를 대신할 경구 소분자 작용제
- 2절 구조 준비: 공개 극저온전자현미경 구조 선택, 결합 포켓 정의, 양성 대조(기존 소분자)
- 3절 화합물 라이브러리 준비(공개 라이브러리), 성질 필터
- 4절 도킹 스크리닝(GPU), 점수 분포와 위양성 점검
- 5절 상위 후보의 분자동역학 재평가와 결합 자유에너지 추정
- 6절 ADMET 예측과 합성 가능성 필터, 최종 후보 목록
- 7절 실험으로 넘기는 방법: 어떤 시험을 어떤 순서로(1부 3장과 연결)
- 입력 파일, 코드, 출력 그림·표, 판정 기준을 모두 수록
- 장비별 실측 소요 시간 표(2부 4장 양식)

**3부 점검:** 독자는 두 사례를 자기 표적과 자기 화합물로 바꿔 재현할 수 있다.
