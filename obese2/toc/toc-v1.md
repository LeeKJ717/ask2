## 0. 이 책의 설계 원리

**목적.** 이 책은 비만치료약물의 작용을 생리학, 세포학, 분자생물학, 유전학, 단백질학으로 풀어 쓴 뒤, 같은 지식을 이용해 독자가 직접 새 약물 후보를 찾는 연구를 설계하고 수행할 수 있게 한다. 책 한 권만으로 문헌 수집, 표적 선정, 신호 모델링, 구조 계산, 후보 설계, 실험 검증 계획까지 닿는다.

**자체완결성을 만드는 장치.** 앞 장의 산출물이 뒤 장의 입력이 되도록 사슬로 묶는다.

| 단계 | 장 | 독자가 손에 쥐는 산출물 | 다음에 쓰이는 곳 |
|---|---|---|---|
| 1 | 3~5 | 몸 전체의 에너지 항상성 회로도(어떤 호르몬이 어떤 장기에 무엇을 하는가) | 6장, 20장 |
| 2 | 6~9 | 수용체에서 유전자 발현까지 이어지는 신호 지도(경로·분자·속도 상수 목록) | 21장 모델 |
| 3 | 10~12 | 유전학·구조 근거로 점수화한 표적 후보표 | 20장, 22장 |
| 4 | 13~17 | 기존 약물 13종의 기전·한계 비교표(미충족 요구) | 18장 목표 설정 |
| 5 | 18~19 | 연구 계획서 틀, 로컬 문헌·데이터 인프라 | 20~24장 |
| 6 | 20~23 | 표적 우선순위 → 신호 모델 → 구조·도킹 → 설계 후보 목록 | 24장 |
| 7 | 24~27 | 검증 실험 설계서, 통계 계획, 특허·규제 전략, 12주 워크스루 | 독자의 실제 연구 |

**각 장의 틀(공통).**
1. 장 도입: 그 개념이 과학사에서 어떤 상황에서 발견되었는지 이야기로 서술(인물, 시대 배경, 실패와 전환점)
2. 핵심 개념: 새 용어는 처음 나올 때 정식 전체 명칭(full name)으로 표기
3. 핵심 논문 해부: 실험 배경 → 과정 → 결과 → 해석(이 책의 근거 논문은 obesepharma_db에서 선정)
4. 그림·표(장당 그림 4~6, 표 2~3), 모든 그림·표에 번호와 제목(그림 3-2, 표 3-2). 표는 한 쪽 안에 배치
5. 6~7부 장은 추가로 **실습 상자**: 오픈소스 명령, 입력·출력 파일, 로컬 GPU 사용법
6. 장 끝: 요약 5줄, 다음 장으로 넘기는 산출물, APA 7판 참고문헌(본문보다 1pt 작게)

**표기 원칙.** 한자어 용어는 한국어 발음으로 적는다(중국어 병음 사용 안 함). 약어는 처음에 전체 명칭과 함께 쓴다.

## 제1부 출발점 (26쪽)

### 1장 비만이라는 병과 약물의 실패사 (12쪽)
- 에너지 수지와 지방조직, 비만 정의와 합병증 개관
- 식욕억제제의 흥망: 실패한 약물들의 공통 원인(작용 선택성 부족, 심장판막·정신과 부작용)
- 표 1-1 과거 비만약물의 작용점·퇴출 사유 / 그림 1-1 비만약물 역사 연표
- DB 연결: clinical_trials, safety_adverse

### 2장 인크레틴의 발견에서 위고비까지 (14쪽)
- 인크레틴 개념의 탄생, 도마뱀 독 펩타이드 이야기, GLP-1 유전자 클로닝, 분해효소 DPP-4라는 걸림돌
- 리라글루타이드, 세마글루타이드, 티르제파타이드로 이어진 약물 설계 계보
- 그림 2-1 발견 연표 / 그림 2-2 약물 계보도 / 표 2-1 주요 임상시험 요약
- DB 연결: physiology, clinical_trials

## 제2부 생리학: 몸 전체에서 (40쪽)

### 3장 에너지 항상성의 뇌: 시상하부, 뇌간, 보상회로 (14쪽)
- 궁상핵(POMC/CART 뉴런, AgRP/NPY 뉴런), 실방핵, 뇌간의 고립로핵과 최후야, 도파민 보상회로
- 미주신경 구심로와 장-뇌 연결
- 그림 3-1 시상하부 회로도 / 그림 3-2 뇌간-시상하부 신호 흐름 / 표 3-1 뉴런 집단별 신경펩타이드와 기능
- DB 연결: physiology, hypothalamic_targets

### 4장 장이 보내는 신호: 호르몬 지도 (14쪽)
- GLP-1, GIP, 펩타이드 YY, 콜레시스토키닌, 그렐린, 옥신토모듈린, 아밀린, 렙틴, 인슐린
- 위 배출 지연, 포만, 식후 호르몬 시간 곡선
- 그림 4-1 호르몬 분비 세포 위치 / 그림 4-2 식후 혈중 농도 곡선 / 표 4-1 호르몬별 수용체·반감기·주요 작용
- DB 연결: physiology, receptor_pharmacology

### 5장 표적 장기: 췌장, 지방, 간, 근육, 신장, 심장 (12쪽)
- 췌도의 α·β·δ 세포, 백색·갈색·베이지 지방, 간 지방증(MASLD), 근육량 보존 문제
- 그림 5-1 장기별 약물 효과 지도 / 표 5-1 장기별 근거 수준
- DB 연결: organ_effects

**2부 점검:** 독자는 호르몬-회로-장기 지도를 완성한다(산출물 1).

## 제3부 세포학과 신호전달 (54쪽)

### 6장 수용체의 세포학: B군 G단백질 연결 수용체와 세포막 (14쪽)
- GLP1R, GIPR, GCGR, 아밀린 수용체(칼시토닌 수용체+RAMP), 수용체 활성화 구조 변화
- Gs, Gq, Gi 선택성, β-아레스틴, 수용체 내재화와 재순환, 엔도솜 신호
- 편향 작용(biased agonism)의 정의와 정량 방법의 개요
- 그림 6-1 수용체 세포 내 이동 경로 / 그림 6-2 편향 작용 모식도 / 표 6-1 수용체별 G단백질 결합 프로파일
- DB 연결: receptor_pharmacology, cell_signaling, cytology

### 7장 cAMP에서 인슐린 분비까지: 신호의 하류 (14쪽)
- cAMP 미세영역, PKA, EPAC2, 칼슘, ATP 민감성 칼륨 채널, 인슐린 과립 분비
- 포도당 의존성의 분자 근거(왜 저혈당 위험이 낮은가)
- 그림 7-1 β세포 신호 지도 / 그림 7-2 시간 척도별 신호 단계 / 표 7-1 분자별 역할·억제제
- DB 연결: cell_signaling, cytology, biochemistry

### 8장 뉴런 안의 신호: 렙틴, 멜라노코르틴, AMPK, mTOR (14쪽)
- 렙틴 수용체-JAK2-STAT3, PI3K-Akt, AMPK와 mTOR의 에너지 감지, MC4R 신호
- 약물이 시상하부 뉴런 신호에 합류하는 지점
- 그림 8-1 뉴런 신호 통합도 / 표 8-1 경로별 약물 개입 가능 지점
- DB 연결: hypothalamic_targets, cell_signaling

### 9장 에너지 기관과 스트레스: 미토콘드리아, 소포체, 오토파지 (12쪽)
- 지방분해 효소(ATGL, HSL), 갈색지방 UCP1, 소포체 스트레스와 β세포 생존, 오토파지
- 그림 9-1 세포 소기관과 약물 효과 / 표 9-1 스트레스 경로 지표
- DB 연결: cytology, biochemistry

**3부 점검:** 독자는 수용체에서 유전자 발현까지의 신호 지도를 완성한다(산출물 2). 21장 모델의 뼈대가 된다.

## 제4부 분자생물학, 유전학, 단백질학 (40쪽)

### 10장 유전자 발현과 후성유전 (12쪽)
- 전사인자 CREB, PDX1 등과 표적 유전자, 약물 반응 전사체, 단일세포 전사체 지도, DNA 메틸화
- 개체-조직-세포-핵-염색체-유전자-mRNA 순서의 그림으로 설명
- 그림 10-1 개체에서 mRNA까지 / 그림 10-2 단일세포 지도 예시 / 표 10-1 약물 처리 후 발현 변화 유전자
- DB 연결: genetics, cell_signaling

### 11장 인간 유전학이 가리킨 표적 (14쪽)
- 단일유전자 비만(LEP, LEPR, POMC, PCSK1, MC4R), 전장 유전체 연관 연구, 멘델 무작위화
- 약물 반응 유전체학: 지금까지의 근거와 한계(과대 해석 금지)
- 그림 11-1 유전학 근거 사슬 / 표 11-1 유전자별 표적 근거 점수
- DB 연결: genetics

### 12장 단백질화학과 구조: 펩타이드 약물 설계와 결합 포켓 (14쪽)
- 아미노산 치환, 지방산 측쇄와 알부민 결합, 반감기 설계, 경구 흡수 보조제
- 극저온 전자현미경 구조가 보여준 리간드-수용체 결합, 소분자 알로스테릭 결합 포켓
- 그림 12-1 펩타이드 설계 요소 / 그림 12-2 수용체-리간드 결합 구조 / 표 12-1 약물별 구조 특징
- DB 연결: proteomics_structure, biochemistry

**4부 점검:** 표적 후보표(산출물 3)를 작성한다.

## 제5부 약물 해부 (58쪽)

### 13장 세마글루타이드와 리라글루타이드, 경구 제형 (12쪽)
- 설계 논리, 핵심 임상시험의 배경·과정·결과·해석, 경구 세마글루타이드의 흡수 기전
### 14장 티르제파타이드와 다중 작용제 (12쪽)
- GIP 작용이 더하는 것에 대한 논쟁, 레타트루타이드 등 삼중 작용제, 서바트루타이드 등 글루카곤 수용체 축
### 15장 경구 소분자: 오포글리프론과 비펩타이드 작용제 (10쪽)
- 소분자가 펩타이드 수용체를 여는 방식, 편향성, 제조·복용 편의의 의미
### 16장 차세대 표적: 아밀린, GDF15, 펩타이드 YY, MC4R, 근육 보존 (14쪽)
- 카그릴린타이드·카그리세마, GDF15-GFRAL 축, 세트멜라노타이드, 액티빈 수용체 경로
### 17장 부작용과 반응 차이의 기전 (10쪽)
- 오심·구토 회로(최후야), 췌장염·담낭 이상 신호, 근손실, 체중 재증가, 반응자와 비반응자
- 각 장 공통: 표(약물 사양), 그림(작용점 지도), 핵심 논문 해부 상자
- DB 연결: clinical_trials, safety_adverse, drug_discovery, hypothalamic_targets

**5부 점검:** 약물 비교표와 미충족 요구 목록(산출물 4). 18장의 목표가 여기서 나온다.

## 제6부 연구 실무: 로컬 GPU로 신약 후보까지 (90쪽)

### 18장 신약 연구의 단계와 의사결정 (10쪽)
- 표적 확인 → 히트 → 리드 → 전임상 → 임상, 단계별 통과·중단 기준
- 연구 계획서 작성법, 한국 식품의약품안전처와 국제 규제의 큰 틀
- 그림 18-1 신약 개발 깔때기 / 표 18-1 단계별 산출물·판정 기준
### 19장 연구 인프라: 문헌 DB, 공개 DB, 로컬 언어모델 (12쪽)
- obesepharma_db 구조와 활용(검색·전문·PDF), 공개 데이터베이스 지도
- 로컬 언어모델 + 검색 증강(RAG)으로 논문 근거 찾기, 인용 검증 절차
- 실습 상자: DB 질의, 임베딩 색인, 인용 자동 점검
### 20장 표적 발굴: 오믹스와 유전통계 재분석 (14쪽)
- 공개 전사체·단일세포 자료 재분석, 유전체 연관 요약통계 기반 유전 상관·공동 국소화·멘델 무작위화
- 표적 점수화 틀(유전학 + 발현 + 구조 가용성 + 안전성 신호)
- 실습 상자: 단일세포 분석, 요약통계 분석 파이프라인
### 21장 신호전달 정량 모델링 (12쪽)
- 상미분방정식으로 GLP1R-cAMP-PKA 모델 구성, 작용 모형(operational model)과 편향 계수 추정
- 매개변수 추정, 민감도 분석, 후보 약물의 신호 프로파일 예측
- 실습 상자: 모델 정의 언어, 시뮬레이션, GPU 가속 매개변수 추정
### 22장 구조 예측, 도킹, 분자동역학 (16쪽)
- 수용체 구조 확보(실험 구조 + 예측 구조), 리간드 도킹, 막단백질 분자동역학, 결합 자유에너지
- 로컬 GPU 메모리 한계 안에서 계산 규모를 정하는 방법
- 실습 상자: 시스템 구성, 평형화, 생산 구동, 분석
### 23장 AI 신약 설계: 소분자와 펩타이드 (14쪽)
- 소분자 생성·스코어링, 펩타이드·단백질 설계, 약동학·독성 예측, 합성 가능성
- 후보 선별 깔때기와 위양성 점검
- 실습 상자: 생성 → 필터 → 도킹 → 동역학 재점수 파이프라인
### 24장 실험 검증 설계와 통계 (12쪽)
