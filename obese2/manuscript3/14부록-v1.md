## 부록

### 부록 A 설치 가이드

장비 한 대를 계산 환경으로 만드는 순서이다. 관리자 권한이 필요한 단계는 장비 관리자가 수행한다.

**표 A-1. 환경 구성 순서와 점검.**

| 순서 | 작업 | 점검 명령(요지) | 통과 기준 |
|---|---|---|---|
| 1 | GPU 드라이버 설치 | `nvidia-smi` | GPU 이름과 드라이버 버전이 보인다 |
| 2 | 환경 관리자 설치(conda 또는 mamba) | `conda --version` | 버전이 나온다 |
| 3 | 도구별 환경 생성 | `conda create -n <이름> python=<버전>` | 환경 목록에 보인다 |
| 4 | 컨테이너 설치(Docker 또는 Apptainer) | `docker run --rm --gpus all <CUDA 이미지> nvidia-smi` | 컨테이너 안에서 GPU가 보인다 |
| 5 | 도구 설치 시험 | `python -m openmm.testInstallation` | 오류 없이 종료 |
| 6 | 환경 정의 내보내기 | `conda env export > env.yml` | 파일이 만들어진다 |

원칙은 도구마다 환경 하나를 만드는 것, 설치 뒤 시험 명령으로 확인하는 것, 환경 정의 파일을 저장소에 기록하는 것이다(9장).

### 부록 B 데이터 사전

obesepharma_db의 열 설명은 실제 스키마에서 뽑아 작성한다. 스키마는 DB 도구로 직접 확인한다(예: SQLite는 `.schema`, MariaDB는 `SHOW CREATE TABLE <표>`). 아래는 기록 양식이다.

**표 B-1. 데이터 사전 양식.**

| 표 | 열 | 형식 | 의미 | 예시 | 비고 |
|---|---|---|---|---|---|
| (표 이름) | (열 이름) | (형식) | (의미) | (값 예) | 결측 규칙, 단위 |

공개 DB 접속(5장 표 5-1)은 각 자료원의 접속 방법, 내려받기 형식, 이용 조건 확인일을 같은 양식으로 `SOURCE.txt`에 기록한다.

### 부록 C 용어집

정식 전체 명칭, 약어, 한국어 설명의 순서이다.

**표 C-1. 용어집.**

| 정식 전체 명칭 | 약어 | 한국어 설명 |
|---|---|---|
| Graphics Processing Unit | GPU | 병렬 계산에 강한 처리 장치 |
| Video Random Access Memory | VRAM | GPU의 메모리, 작업 크기를 정한다 |
| Retrieval-Augmented Generation | RAG | 근거를 먼저 찾고 그것으로 답하게 하는 방식 |
| Absorption, Distribution, Metabolism, Excretion, Toxicity | ADMET | 흡수·분포·대사·배설·독성 |
| Pan-Assay Interference Compounds | PAINS | 여러 시험에서 거짓 양성을 내는 구조 경고 |
| Mendelian Randomization | MR | 유전 변이를 도구로 인과를 추정하는 방법 |
| Enrichment Factor | EF | 상위 일부에서 활성 분자가 얼마나 농축되었는지 |
| Area Under the Curve | AUC | 구분력을 요약하는 곡선 아래 면적 |
| Effective Concentration 50 | EC50 | 최대 반응의 절반을 내는 농도 |
| Operational Model of Agonism | — | 친화도와 전달 능력으로 반응을 설명하는 모형 |
| Molecular Dynamics | MD | 원자의 시간에 따른 움직임을 계산하는 방법 |
| Standard Deviation | SD | 표준편차 |

### 부록 D 재현성 체크리스트와 저장소 구조

9장 표 9-1의 점검표를 쓰고, 저장소는 다음 폴더로 구성한다.

**표 D-1. 저장소 구조.**

| 폴더 | 담는 것 |

| `config/` | 설정 파일, 시드, 사전 기록한 판정 기준 |

| `logs/` | 실행 이력 표, 도구 로그 |

### 부록 E 사례 1·2 파일 목록

**표 E-1. 사례 파일과 실행 방법.**

| 사례 | 파일 | 역할 | 실행 |
|---|---|---|---|
| 1 | `code3/case1/gensynth.py` | 참값에서 가상 용량-반응 자료 생성 | `python3 gensynth.py` |
| 1 | `code3/case1/fitom.py` | 곡선 적합, 편향 계수, 부트스트랩 | `python3 fitom.py` |
| 1 | `code3/case1/glp1ode.py` | 신호 경로 모델, 매개변수 격자 탐색 | `python3 glp1ode.py` |
| 2 | `code3/case2/propfilter.py` | 성질 필터와 PAINS 표시 | `python3 propfilter.py 입력.csv 출력.csv` |
| 2 | `code3/case2/enrich.py` | AUC와 농축 계수 계산 | `python3 enrich.py` |

모든 코드는 python 3과 numpy, scipy, RDKit, scikit-learn으로 실행되며, 가상 자료와 가상 매개변수를 쓴다. 자기 연구에서는 입력 파일을 같은 열 이름으로 바꾸어 같은 명령으로 돌린다.
