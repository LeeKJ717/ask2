# 책에 넣을 지도 그리는 법

『피타고라스적 삶에 관하여』 v4에서 쓴 방법을 정리해 둔다. 다른 책에서도 이대로 하면 된다.

핵심은 셋이다.

1. **해안선을 손으로 찍지 않는다.** 공개 지리 자료(Natural Earth)의 실제 좌표를 쓴다.
2. **1단위 = 0.1mm로 약속한다.** 그러면 글자 크기를 인쇄 기준으로 바로 계산할 수 있다.
3. **지도마다 전체 위치도(인셋)를 넣는다.** 확대한 그림만 있으면 어디인지 알 수 없다.

## 2. 크기 약속 — 1단위 = 0.1mm

이것이 이 방법의 핵심이다. SVG의 viewBox 단위를 **0.1mm**로 못 박는다.

- 인쇄 폭 116mm 짜리 지도 → `width = 1160` 단위
- 인쇄 폭 82mm 짜리 지도 → `width = 820` 단위

그러면 **글자 크기를 인쇄 기준으로 바로 정할 수 있다.**

| 쓰임 | 단위 | 인쇄 크기 | 포인트 |
|---|---|---|---|
| 그림 제목 | 38 | 3.8mm | 10.8pt |
| 큰 지명·나라 이름 | **30** (`FS`) | 3.0mm | **8.5pt** |
| 보통 지명·범례 | **26** (`FS_S`) | 2.6mm | 7.4pt |
| 인셋 글씨·주석 | **23** (`FS_I`) | 2.3mm | 6.5pt |

> 환산: `pt = 단위 × 0.1 ÷ 0.3528`
> **8pt 아래로 내려가지 않게 한다.** 책에 들어가면 생각보다 훨씬 작다.

### 판면에 맞는 크기 정하기

신국판(152×225mm, 여백 22/18/19/18)의 본문 폭은 **116mm**, 높이는 **168mm**가 한도다.
`fit(bbox)`가 이 한도 안에서 캔버스 크기를 정해 준다.

```python
def fit(bbox):
    lo0, la0, lo1, la1 = bbox
    cosm = math.cos(math.radians((la0 + la1) / 2))
    asp  = (la1 - la0) / ((lo1 - lo0) * cosm)   # 세로/가로 비
    wmm  = min(116.0, 168.0 / asp)              # 인쇄 폭(mm)
    return wmm * 10.0, wmm * 10.0 * asp         # 단위
```

세로로 긴 지역(이집트 같은)은 폭이 저절로 줄어든다. 그래도 **1단위 = 0.1mm는 변하지 않으므로 글자 크기는 그대로 쓰면 된다.**

## 3. 도법 — 위도 보정을 반드시 한다

경도 1도와 위도 1도의 실제 거리는 다르다. 위도 38도에서 경도 1도는 약 88km, 위도 1도는 약 111km다.
그냥 그리면 동서로 늘어난 지도가 된다. **가운데 위도의 코사인을 곱해 가로를 줄인다.**

```python
class Proj:
    def __init__(self, bbox, w, ox=0.0, oy=0.0):
        lo0, la0, lo1, la1 = bbox
        self.cos = math.cos(math.radians((la0 + la1) / 2.0))
        self.k   = w / ((lo1 - lo0) * self.cos)     # 1도당 단위
        self.h   = (la1 - la0) * self.k
    def __call__(self, lon, lat):
        return (self.ox + (lon - lo0) * self.cos * self.k,
                self.oy + (la1 - lat) * self.k)     # 위도는 위아래가 뒤집힌다
    def km(self, km):
        return km / 111.32 * self.k                 # 축척 막대용
```

이 정도면 한 화면에 들어오는 지역에서는 충분하다. 대륙 전체를 그릴 때만 왜곡이 눈에 띈다.

## 4. 자르기와 간략화

**자르기** — 지구 전체 폴리곤에서 필요한 사각형만 오려 낸다.
서덜랜드–호지먼(Sutherland–Hodgman) 알고리즘을 쓴다. 자르는 영역이 사각형(볼록)이므로 이 방법이 맞는다.

**간략화** — 그대로 그리면 SVG가 수 MB가 된다. 더글러스–포이커로 줄인다.
기준은 **출력 0.7단위(=0.07mm)**. 인쇄에서 보이지 않는 굴곡을 버리는 셈이다.

```python
eps = 0.7 / pr.k        # 출력 단위 → 도(度) 단위로 환산
```

이렇게 하면 한반도 지도가 160KB 안팎으로 떨어진다.

> **주의** — 폴리곤의 구멍(내부 고리)도 육지 색으로 칠해진다. 큰 호수가 있는 지역은
> `basemap(..., lakes=True)`로 호수를 따로 덮어 그린다.

## 5. 지도 한 장 그리기

```python
# -*- coding: utf-8 -*-
import figs_maps as M          # geo_kit 에서 복사해 온 것
from figs_maps import city, inset, scalebar, basemap, finish, P, FS, FS_S

def m_example():
    bbox = (116.5, 32.8, 132.0, 44.2)          # (서, 남, 동, 북)
    f, pr = basemap(bbox, pad=290)             # pad = 아래 설명띠 높이(단위)

    # ① 바다·지역 이름 (지명이 아닌 것은 흐린 색으로)
    f.text(*pr(124.2, 35.6), s="황  해", size=FS, anchor="middle",
           fill="#6E8CA0", weight=700)

    # ② 지명 — (경도, 위도, 이름, dx, dy, 정렬, 강조)
    for lon, lat, nm, dx, dy, an, big in [
        (126.48, 37.70, "강화", 14, 8, "start", False),
        (125.90, 38.55, "평양", -14, 8, "end",  True),
    ]:
        city(f, pr, lon, lat, nm, dx, dy, an, big)

    # ③ 전체 위치도 — 넓은 범위, 본그림 범위가 붉은 네모로 표시된다
    inset(f, (95, 15, 150, 55), bbox, 820, 128, 300,
          marks=[(126.9, 37.5, "한반도", 9, 6, "start")])

    # ④ 축척 막대
    scalebar(f, pr, 760, 1040, 200)            # 200km

    # ⑤ 아래 설명띠 (pad 로 만들어 둔 자리)
    f.line(0, pr.h, f.w, pr.h, stroke="#C7BCA4", sw=2)
    f.text(28, pr.h + 44, "범례 제목", size=FS, weight=700, fill=P["brown"])

    finish(f, "map_example.svg", "※ 해안선은 실제 자료")
```

### 지명 표시 기호

`city(..., mark=...)` 로 고른다. 유물 분포도처럼 종류를 나눌 때 쓴다.

| mark | 모양 | 쓰는 곳 |
|---|---|---|
| `"dot"` (기본) | 동그라미 | 보통 도시. `big=True`면 붉게 커진다 |
| `"star"` | 별 | 가장 중요한 곳(유적 등) |
| `"sq"` `"tri"` `"dia"` | 네모·세모·마름모 | 분포도에서 유물 종류 구분 |

## 6. 인셋(전체 위치도) — 반드시 넣는다

확대한 지도만 있으면 어디인지 알 수 없다. `inset()`이 다음을 한 번에 해 준다.

- 넓은 범위를 `ne_50m_land`로 거칠게 그린다
- **본그림의 범위를 붉은 네모**로 표시한다
- 방향을 잡아 줄 기준점 한둘을 찍는다 (예: 여정 지도의 인셋에 '한반도')

```python
inset(f, obox, dbox, x, y, w, marks=[(경도, 위도, "이름", dx, dy, "정렬")])
#      └넓은 범위  └본그림 범위  └왼위 모서리와 폭(단위)
```

**놓을 자리** — 본그림에서 지명이 없는 바다나 사막 쪽. 자리가 없으면 `pad`로 아래 띠를 만들어 거기 넣는다(사모스 지도가 그렇게 했다).

## 7. 조판에 붙이기

SVG를 그냥 넣으면 브라우저/WeasyPrint가 제 나름의 크기(px)로 해석해 축소·확대한다.
**본디 크기에서 인쇄 폭(mm)을 계산해 `<img>`에 직접 지정한다.**

```python
MAXW_MM, MAXH_MM = 116.0, 168.0

def svg_mm(src):
    head = open(os.path.join(DIR, src), encoding="utf-8").read(600)
    w = float(re.search(r'width="([\d.]+)"',  head).group(1))
    h = float(re.search(r'height="([\d.]+)"', head).group(1))
    return round(min(MAXW_MM, MAXH_MM / (h / w)), 1)

# 마크다운의 ![캡션](../figs/x.svg) → <figure>
html = ('<figure class="fig"><img src="%s" style="width:%smm"/>'
        '<figcaption>%s</figcaption></figure>' % (src, svg_mm(src), alt))
```

CSS는 이렇게 둔다.

```css
.fig     { margin:8pt 0 10pt 0; text-align:center; page-break-inside:avoid; }
.fig img { max-width:100%; }
.fig figcaption { font-size:8.2pt; color:#6B6254; margin-top:3pt; }
/* 해설 상자 안에 그림이 들어갈 때, 상자의 안쪽 여백만큼 밖으로 빼서 폭을 다 쓴다 */
.bg .fig { margin-left:-11pt; margin-right:-11pt; }
```

> **지도를 가로로 눕히지 말 것.** 읽는 사람이 책을 돌려야 한다.
> 지역이 가로로 길면 범위를 좁히거나 두 장으로 나눈다. 세로로 길면 폭이 줄 뿐 문제없다.

## 8. 자주 걸리는 것들

| 증상 | 까닭과 해법 |
|---|---|
| 바다가 육지로 칠해진다 | 해안선을 손으로 찍으면 폴리곤이 엉킨다. → **자료를 쓴다** |
| 지명이 왼쪽/오른쪽에서 잘린다 | `anchor="end"`인 라벨이 그림 밖으로 나간 것. bbox를 조금 넓히거나 `anchor`를 반대로 |
| 라벨끼리 겹친다 | `dx, dy`로 밀어낸다. 그래도 안 되면 두 줄로 쪼개거나(`\n`) 한쪽을 범례로 뺀다 |
| 인셋이 지명을 덮는다 | 인셋은 **마지막에** 놓고, 빈 바다·사막 쪽으로. 자리 없으면 `pad`로 아래 띠를 만든다 |
| 범례 상자가 지도를 가린다 | 상자를 본그림 안에 두지 말고 `pad` 띠로 내린다 |
| 작은 섬이 안 나온다 | `ne_10m_minor_islands`도 함께 읽는다 (`srcs=(...)` 기본값에 들어 있다) |
| 강이 안 보인다 | `ne_10m_rivers_lake_centerlines`에 없는 작은 강일 수 있다. `namefilter="Nile"`로 확인 |
| SVG가 너무 무겁다 | 간략화 기준 `eps_units`를 0.7 → 1.0 으로 올린다 |
| 글자가 인쇄물에서 작다 | **1단위 = 0.1mm 약속을 어긴 것.** 캔버스 폭이 `인쇄 mm × 10`인지 확인 |
| 화살표가 거꾸로 달린다 | librsvg는 `orient="auto-start-reverse"`를 뒤집는다. `orient="auto"`를 쓴다(figlib는 이미 그렇게 되어 있다) |
| 재귀 오류 | 더글러스–포이커가 깊어진 것. `simplify()`가 한도를 올렸다 내린다 |

```bash
mkdir -p ~/책폴더/scripts ~/책폴더/figs
cp ~/mdfile/geo_kit/{geomap.py,figlib.py,figs_maps.py} ~/책폴더/scripts/
```

- `figs_maps.py`의 `OUT`은 **스크립트 폴더의 `../figs`**를 가리킨다. 그 폴더를 미리 만들어 둘 것.
- `geomap.py`의 `GEO`는 `~/dball/geo`를 본다. 자료를 다른 데 두었으면 이 줄만 고친다.
- 자료를 읽는 데 1~2초 걸린다. 한 번 읽으면 메모리에 남으므로 **여러 지도를 한 스크립트에서 만드는 편이 빠르다.**
