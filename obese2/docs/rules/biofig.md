## 0. 한 쪽 요약

1. **그림은 좌표를 직접 적은 SVG로 만든다.** 파이썬 스크립트가 도형·곡선·글자를 하나하나 좌표로 찍어 SVG 파일을 쓴다. 외부 이미지·그림 프로그램·matplotlib 을 쓰지 않는다.
2. **캔버스는 폭 800단위 = 인쇄 120mm.** 1단위 = 0.425pt. **그림 속 글자는 22단위(9.4pt) 이상.**
3. **글자 폭을 먼저 계산하고 상자를 정한다.** 한글 1자 = 글자크기 × 1.0, 영문·숫자 = × 0.58.
4. **복잡한 형태(세포·기관·식물)는 도형 안에 글자를 넣지 않고, 바깥 여백에 라벨을 세로로 줄 세운 뒤 회색 리더선으로 잇는다.**
5. **형태는 베지어 곡선으로 실제 모양을 따라 그린다.** 미토콘드리아는 이중막과 크리스타, 핵은 이중막과 핵공, 세포막은 약간 흔들리는 곡선.
6. **색은 의미별로 책 전체에 통일**(정상=파랑, 암=주황갈색, 면역=초록, 성분=금색, 보조=회색)하고, 같은 색의 **명도 단계**로 입체감을 낸다. 흑백 인쇄에서도 구분되어야 한다.
7. **검사는 사람 눈 이전에 기계가 한다**: ① 글자↔글자 겹침 ② 캔버스 넘침 ③ 상자 넘침 ④ 글자를 가리는 도형 ⑤ 글자 크기 하한 ⑥ **포함 검사(소기관이 세포 밖으로 나가는지)**. 모두 0건이어야 한다.
8. 그다음 **PNG로 떠서 컬러·흑백을 눈으로 본다.** 기계가 못 잡는 어색함(겹쳐 보이는 소기관, 리더선 교차)을 여기서 잡는다.
9. **데이터 그래프의 숫자는 논문 초록·DB 통계에서 온 값만** 쓰고, 스크립트 안에서 합계를 `assert`로 대조한다.
10. 그림 안에는 그림 번호·제목을 넣지 않는다. 캡션(번호 + 제목 + 무엇을 보는지 + 주의점, 모식도면 "모식도")은 원고에서 붙는다.

## 1. 왜 좌표 SVG인가

| 방식 | 문제 | 좌표 SVG의 해결 |
|---|---|---|
| 그림 프로그램(수작업) | 고치기 어렵고, 판본마다 다시 그려야 함 | 스크립트 한 줄 고치고 다시 실행 |
| matplotlib | 글자 크기·위치 통제가 약하고 생물 형태를 못 그림 | 모든 요소를 좌표로 통제 |
| 외부 이미지 | 저작권·해상도 | 직접 그린 벡터, 인쇄 해상도 무관 |
| AI 이미지 | 글자·해부학 오류, 재현 불가 | 과학적으로 검증 가능한 형태 |

그리고 가장 큰 이유: **글자의 위치와 크기를 알고 있으므로 겹침을 자동으로 검사할 수 있다.** 이 책 53점은 모두 자동 검사 0건 + 눈 검수를 통과했다.

## 2. 좌표계와 글자 크기 계산

```
viewBox 폭 800  →  인쇄 폭 120mm (신국판 본문 폭 안)
1단위 = 120/800 mm = 0.15mm = 0.425pt
글자 22단위 = 9.4pt  (하한)      book1.md의 "700폭에서 18(8.2pt)"보다 엄격
본문 라벨 22~24, 제목·강조 26~30, 큰 수치 28~32
높이는 자유: 보통 360~700 (700이면 인쇄 105mm)
```

**글자 폭 추정**(figlib `_w()`, 검사기와 같은 식):

| 문자 | 폭(× 글자크기) |
|---|---|
| 한글·한자 | 1.00 |
| 영문 대소문자·숫자 | 0.58 (m, w는 0.85) |
| 공백, `i l j . , · ( ) [ ] : ;` | 0.32 |

예) 24단위로 "미토콘드리아"(6자) = 144단위 → 상자 폭은 최소 144 + 좌우 여백 12 = 156 이상.
실제 한글은 약 0.92em이라 이 추정은 **약간 보수적**이다(넘침을 확실히 막는다).

**줄 간격** = 글자크기 × 1.28~1.32. **글자 사방 여백** 6단위 이상.

## 3. 도구

### 3-1 `figlib.py` — 그림 한 장 = `Fig` 객체 하나

```python
import figlib as F
from figlib import Fig, INK, BLUE, LBLUE, GRAY, WARM, LWARM, GREEN, GOLD, WHITE

f = Fig('fig13_1.svg', 620)                  # 이름, 높이(폭은 800)
f.rect(x, y, w, h, fill, stroke, sw, rx)     # 도형들: rect circle ellipse line path poly
f.path(d, stroke, sw, fill)                  # 베지어 곡선(path d 문자열)
f.text(x, y, '글자', 24, 700, 'middle')      # 글자 — 반드시 text/tbox/callout으로 넣는다(검사 대상)
f.tbox(x, y, w, h, ['첫 줄', '둘째 줄'], 24, first_bold=True)   # 글자 상자, 넘치면 경고
f.callout(px, py, lx, ly, ['라벨'], 24, 'end', weight=700, sub='english')  # 리더선 라벨
f.arrow(x1, y1, x2, y2)  f.carrow(x1,y1,cx,cy,x2,y2)  f.inhibit(...)       # 화살표·곡선 화살표·억제(⊣)
f.badge(cx, cy, '1')                          # 순서 번호 원(①②③)
f.axis_label(x, y, '논문 수(편)')             # 세로축 제목(90도 회전)
f.raw('<g transform=...>')                    # 직접 쓴 SVG 조각(글자는 넣지 말 것)
f.save(OUT)                                   # 저장 + 자동 검사
F.contain(f.name, '골지체', 윤곽점, 검사점)    # 포함 검사(4-6항)
F.report()                                    # 경고 목록 출력 — 0건이어야 완성
```

`save()`가 하는 검사: 글자↔글자 겹침(6% 초과), 캔버스 밖 넘침, 글자 위에 나중에 그린 불투명 도형(가림), 글자 크기 하한. `tbox()`는 상자 폭·높이 넘침을, `contain()`은 윤곽 밖으로 나간 점을 경고한다.

## 4. 작업 흐름 (그림 한 점)

### 4-1 설계 — 그리기 전에 종이에

1. **이 그림이 답할 질문 한 줄**을 적는다. ("세포자멸사는 미토콘드리아에서 어떤 순서로 일어나나?")
2. **형태 그림인가, 관계 도식인가, 데이터 그래프인가**를 정한다(8·9항 레시피가 다르다).
3. 캔버스를 **영역으로 나눈다**: 그림 본체 영역 / 왼쪽 라벨 열(x ≈ 20~170) / 오른쪽 라벨 열(x ≈ 630~790) / 아래 범례·순서 설명 영역.
4. 라벨 목록을 먼저 쓰고 **가장 긴 라벨의 폭**을 계산해 라벨 열 폭을 정한다.

### 4-6 포함 검사 (이번 책에서 새로 만든 검사)

형태 그림에는 **"A는 B 안에 있어야 한다"**는 해부학적 제약이 있다. 소기관은 세포막 안, 핵소체는 핵 안, 종양은 간 안, 막단백은 막을 가로질러야 한다. 이것은 글자 겹침 검사로 잡히지 않는다. `figlib.contain()`으로 검사한다.

```python
inner = S.outline(CX, CY, RX, RY, WOB, 16, scale=0.968)   # 세포막 '안쪽 선' 바로 안의 윤곽(2도 간격)
F.contain(f.name, '골지체', inner, golgi_pts)                # 주머니 외곽점 + 소낭 둘레점
F.contain(f.name, '미토콘드리아', inner, S.mito(f, 283, 190, -28))   # mito()가 실제 윤곽점을 돌려준다
```

- 검사할 점은 **실제 윤곽 위의 점**으로 뽑는다. 캡슐·원의 바운딩 사각형 모서리를 쓰면 둥근 모서리 바깥이라 과잉 경고가 난다(`capsule_outline` 사용).
- 윤곽 다각형은 **그린 곡선과 똑같은 식**으로 뽑는다. `blob_pts(n=64)`처럼 흔들림 표(16개)와 점 개수가 다르면 모양이 달라져 검사가 틀린다 → `outline()`(= `on_blob` 2도 간격)을 쓴다.
- 여유: 세포막을 두 줄(바깥 1.0, 안쪽 0.972)로 그렸다면 검사 윤곽은 **0.965~0.968** — 소기관이 막 두께 띠에 걸치지 않게.

규칙(book1.md 4-2):
- **한 그림 4~6색.** 입체감은 색을 늘리지 말고 **같은 색상의 명도 3~4단계**로(예: 미토콘드리아 외막 `#e6eaec` · 기질 `#aebbc2` · 선 `#44545d`).
- 채도 낮은 색만. 형광·원색 금지.
- **인접 구조의 명도 차 20% 이상**. 흑백 PNG(`_gray.png`)에서 두 구조가 같은 회색이면 한쪽 명도를 바꾼다(예: 진세노사이드 채움을 DGOLD로 더 짙게 해 단백질 몸통과 구분).
- 흑백에서 **유의/비유의**는 색이 아니라 **속찬/속빈 표지**로, **사람 근거/실험실 근거**는 **색 + 모양**(원 속채움·테두리만)으로 구분.
- 다른 책에서는 **의미만 바꿔** 쓴다. 뇌 책이면 BLUE=신경세포, GREEN=교세포, WARM=손상·염증, GOLD=약물·영양소.

## 6. 라벨 규칙 (학술지형 도해의 핵심)

1. **형태가 복잡한 그림은 도형 안에 글자를 넣지 않는다.** 라벨은 도형 바깥 여백에 둔다.
2. 라벨은 **왼쪽 열(오른쪽 끝 정렬, `anchor='end'`)과 오른쪽 열(왼쪽 끝 정렬, `'start'`)**에 세로로 줄 세운다. 예) 그림 2-1: 왼쪽 x=168에 세포막·미토콘드리아·핵막 구멍·소포체·리소좀, 오른쪽 x=628에 골지체·핵소체·핵·리보솜.
3. **리더선끼리 교차 금지.** 왼쪽 열은 왼쪽 부위, 오른쪽 열은 오른쪽 부위를 맡고, **라벨의 위→아래 순서를 부위의 위→아래 순서와 같게** 하면 교차가 생기지 않는다.
4. 리더선은 회색 1.2단위, 부위 쪽 끝에 작은 점(r 3.2). 라벨 글자에서 6단위 떨어져 끝난다(`callout`이 자동 처리).
5. 리더선의 부위 쪽 끝점은 **계산해서** 얻는다: 세포막이면 `on_blob(…, 각도)`, 소포체면 주머니 끝점, 골지체면 가장 바깥 소낭(`max(pts, key=…)`). 눈대중 좌표는 도형이 옮겨지면 허공을 가리킨다.
6. **한글 명칭 우선, 아래 줄에 회색 작은 글씨로 원어**(`sub='mitochondria'`). 원어가 길면 두 줄로 나눈다(endoplasmic / reticulum).
7. 과정 그림: 단계마다 `badge()`로 ①②③, 화살표에는 짧은 동사("켠다", "자른다", "떨어진다"). 아래에 번호별 한 줄 설명을 모은 범례를 둔다(그림 13-1, 24-1, 34-1).
8. 화살표는 **글자 상자 경계 바깥에서 시작하고 끝난다.** 선 위에 글자를 얹지 않는다.
9. 흐름도·순서도처럼 **상자 자체가 내용인 그림**만 상자 안에 글자를 넣는다(`tbox`, 폭 먼저 계산).

## 7. 곡선 형태 기법

### 7-1 매끈한 곡선 = 점 몇 개 + Catmull-Rom
유기적 형태는 **통과할 점을 8~16개 정하고 `smooth()`로 이으면** 끝이다. 제어점을 손으로 잡을 필요가 없다.

### 7-2 살아 있는 윤곽 = 흔들리는 타원
```python
WOB = (0.02, 0.035, 0.01, -0.02, -0.03, 0.0, 0.03, 0.02, -0.01, -0.035, -0.015, 0.02, 0.035, 0.0, -0.025, -0.01)
cell = S.blob_pts(CX, CY, RX, RY, WOB, 16)          # 반지름을 ±3% 흔든 16점
f.path(S.smooth(cell), BLUE, 3.2, '#f2f7f9')          # 바깥 막
f.path(S.smooth(S.blob_pts(CX, CY, RX, RY, WOB, 16, scale=0.972)), '#86a8bb', 1.3)  # 막 두께를 나타내는 안쪽 선
```
- 정상세포: 흔들림 ±2~3%, 매끈.  **암세포**: 느린 굴곡(sin 3·5파) + 잔돌기(4점마다 +35%) + 무작위 → `cancer_cell()`.
- **무작위는 반드시 `random.Random(seed)`로 고정**한다. 다시 실행해도 같은 그림이 나와야 판본 비교가 된다.

### 7-3 이중막 = 같은 윤곽을 두 번(배율만 다르게)
핵막: `scale=1.0`(바깥막, 중간 명도 채움) + `scale=0.94`(안쪽막, 옅은 채움) → 두 막 사이 틈이 명도로 보인다. 핵막 구멍은 이중막을 가로지르는 **배경색 굵은 선(틈)** + 양쪽 **작은 점(구멍 복합체)**.

### 7-4 오프셋 곡선 = 다른 구조를 감싸는 막
소포체는 핵 윤곽의 법선 방향으로 d만큼 떨어진 곡선 두 개(d±5)를 이어 **주머니**를 만든다. 핵 둘레를 3겹(d=22, 40, 58) 감싸고, 바깥면에 리보솜 점(r 2.4)을 찍는다.

### 7-5 부품은 원점에서 그리고 옮긴다
```python
S.g_open(f, x, y, rot)      # translate + rotate
...원점 기준 좌표로 그리기...
S.g_close(f)
```
미토콘드리아·세균·적혈구·잎처럼 여러 번 쓰는 부품. 포함 검사를 위해 **변환된 실제 좌표의 윤곽점을 함수가 돌려주게** 만든다(`mito()`의 반환값).

### 7-6 점묘(자유 리보솜·과립) = 피할 구역을 둔 무작위 산포
```python
avoid = [(372, 318, 128, 116), (457, 201, 66, 58), ...]   # (중심x, 중심y, 반폭, 반높이) 타원들
while len(dots) < 110:
    ... 세포 안 무작위 점 → avoid 타원 안이면 버림
```
**소기관을 옮기면 avoid 목록도 같이 옮긴다**(안 그러면 점이 소기관 위에 뿌려진다).

### 7-7 배치를 계산으로 찾기 — 격자 탐색
좁은 공간에 부품을 넣을 때 좌표를 눈대중으로 바꾸며 반복하지 말고, **후보 좌표를 격자로 훑어 모든 제약을 만족하는 자리 중 원래 자리에서 가장 가까운 곳**을 고른다.
```python
for x in range(...): for y in range(...): for rot in (...):
    P = S.capsule_outline(x, y, rot, L, W)
    if 막_안(P) and 소포체와_간격(P) >= 7 and 리소좀과_안_겹침(P):
        cost = 이동거리 + 회전*0.5 + 축소량*1.5  → 최소 선택
```
그림 2-1 수정 때 골지체·미토콘드리아·리소좀 자리를 이렇게 정했다(11항).

- **숫자는 초록·DB 통계에 있는 값만.** 스크립트에서 파일(`stats.json` 등)을 직접 읽어 그리고, 손으로 옮겨 적지 않는다.
- 축 눈금·단위·출처(각주)를 넣는다. 로그축은 캡션에 "로그 눈금"을 밝힌다.
- 서로 다른 척도(OR과 HR)를 한 그림에 넣으면 표지 모양을 달리하고 캡션에 적는다.
- **하위집단 값만 골라 그리면 편향된 그림이 된다.** 전체 결과가 "연관 없음"이면 그 사실을 그림이나 캡션에 함께 적는다(24-2 캡션 참조).

## 10. 검사 체계 (book1.md 5항의 구현)

| 단계 | 도구 | 잡는 것 | 통과 기준 |
|---|---|---|---|
| 1 | `figlib` (save/report) | 글자↔글자 겹침, 캔버스 넘침, 가림, 글자 하한, tbox 넘침, **포함 위반** | 0건 |
| 2 | `check_figs.py` | 최종 SVG 독립 재검사(스크립트 밖 수정·raw 글자 포함) | 0건 |
| 3 | `preview_figs.sh` + 눈 | 소기관끼리 겹쳐 보임, 리더선 교차, 어색한 비례, 해부학 오류 | 사람 판단 |
| 4 | 흑백 PNG | 인접 구조 명도 차, 유의/비유의 구분 | 모두 구분 |
| 5 | 조판 후 쪽 PNG | 그림 크기·캡션·쪽 넘김 | 사람 판단 |

**경고가 나면**: 글자를 줄이지 않는다. ① 상자·라벨 열을 넓히거나 ② 그림 높이를 키우거나 ③ 문구를 줄이거나(두 줄로) ④ 내용을 덜어낸다. 하한(22단위) 미만은 figlib이 강제로 22로 올리고 경고한다.

**자동 검사가 못 잡는 것**(3단계에서 반드시 볼 것): 소기관끼리의 겹침(포함 검사는 "안에 있나"만 봄), 리더선이 다른 도형을 가로지름, 비례(핵이 너무 큼), 화살표 방향 오류, 과학적 사실 오류.

## 11. 실패 사례와 교훈

1. **골지체가 세포 밖으로 나갔다(그림 2-1, v1).**
   - 원인: 골지체 중심을 눈대중 좌표(512, 178)로 정하고 주머니 길이(118)와 소낭을 붙였는데, 세포막이 그 방향으로 둥글게 들어와 있었다. 겹침 검사는 **글자**만 보므로 도형의 해부학적 위치 오류를 잡지 못했다. 사람 눈 검수에서도 놓쳤다.
   - 해결: `figlib.contain()`(점-다각형 포함 검사)을 새로 만들고, 골지체 외곽점 58개가 막 밖에 있음을 재현했다. 막 안쪽 여유선 안·핵과 미토콘드리아에서 떨어진 곳·리더선이 지나가지 않는 곳을 **격자 탐색**으로 찾아 (452, 208), 주머니 길이 100으로 옮겼다. 골지체는 실제 세포에서도 핵 옆에 있으므로 해부학적으로도 더 맞다.
   - 덤으로 잡힌 것: 같은 검사가 **아래쪽 미토콘드리아 두 개가 막 두께 띠를 넘은 것**도 찾아냈다(눈으로는 못 봄). 원래 배치에서 가장 적게 움직이는 자리를 탐색해 고쳤다.
   - 교훈: **형태 그림은 "무엇이 무엇 안에 있어야 하는가" 목록을 만들고 모두 `contain()`으로 검사한다.**
2. **검사 윤곽을 그린 곡선과 다른 식으로 만들면 검사가 틀린다.** `blob_pts(…, n=64)`는 흔들림 표 16개를 4번 반복해 다른 모양이 된다 → `outline()` 사용.
3. **바운딩 사각형으로 포함 검사를 하면 과잉 경고**(캡슐의 둥근 끝). 실제 윤곽점을 쓴다.
4. **소낭이 핵막에 붙어 보였다.** 핵과의 정규화 거리 1.22배 이내 소낭을 자동으로 빼는 규칙을 넣었다. "가까움"도 규칙으로 만든다.
5. **그림 속 글자를 줄여 해결하려 하지 말 것.** 하한을 지키고 그림을 키우거나 덜어낸다.
6. **큰 그림은 조판에서 빈칸을 만든다.** 높이 130mm 이상 그림이 쪽 끝에 걸리면 다음 쪽으로 밀리며 앞 쪽이 비었다 → 조판 스크립트의 "그림 흘리기"(뒤 문단을 끌어올림)로 해결. 가능하면 그림 높이를 110mm(700단위) 이하로 설계한다.
7. **데이터 그래프의 수치는 사실 검증 대상이다.** 이 책은 그림 숫자까지 초록과 대조했다(오류 0). 하위집단 값만 그린 숲그림(24-2)은 캡션에 전체 결과를 보탰다.
8. **공용 라이브러리는 한 사람만 고친다.** 여러 집필자가 동시에 그릴 때는 각자 `figs_wN.py` 안에서 `Fig`를 상속하거나 도우미 함수를 만들게 했다. 좋은 도우미는 나중에 `shapes.py`로 올린다(이번 킷이 그 결과).

## 12. 다른 책에 적용하는 순서

1. 킷 복사: `cp ~/mdfile/biofig_kit/{figlib.py,shapes.py} <책>/build/ ; cp ~/mdfile/biofig_kit/{check_figs.py,preview_figs.sh} <책>/tools/`
   (도구 두 개는 **책 프로젝트 루트에서 실행**하면 `fig/`, `preview/`를 쓴다.)
2. `figlib.py` 머리의 **색 의미 표**를 그 책에 맞게 다시 정한다(색 값은 그대로, 의미만).
3. 장 묶음마다 `build/figs_<묶음>.py`를 만든다(4-2 틀). 부품은 `import shapes as S`.
4. 형태 그림마다 **포함 관계 목록**을 먼저 쓰고 `contain()`을 넣는다.
5. 실행 → 검사 0 → PNG·흑백 눈 검수 → 원고에 `<<FIG …>>` → 조판.
6. 여러 집필자(에이전트)에게 맡길 때는 설계서에 아래 문단을 그대로 붙인다.

```
## 그림 규칙
- SVG를 좌표로 직접 그린다. build/figlib.py·shapes.py를 먼저 읽을 것. 스크립트는 build/figs_wN.py.
- viewBox 폭 800(출력 120mm). 글자 22 이상(≈9.4pt), 제목 26~30.
- 글자 폭을 먼저 계산하고 상자를 정한다(한글 1자 ≈ 글자크기, 영문·숫자 ≈ 0.58배).
- 복잡한 형태는 도형 안에 글자를 넣지 말고 바깥 라벨 열 + callout() 리더선. 리더선 교차 금지.
- 실제 형태 반영(베지어 곡선, 이중막, 크리스타, 핵공). 원·사각형으로 때우지 않는다.
- 색 의미: 정상=BLUE, 암=WARM, 면역=GREEN, 성분=GOLD, 보조=GRAY. 한 그림 4~6색, 인접 명도 차 20% 이상.
- 소기관·장기 속 구조는 figlib.contain()으로 포함 검사.
- 그림 안에 번호·제목 금지(캡션이 붙는다). 과정은 badge()로 ①②③.
- 수치 그래프는 초록/통계 파일 값만, 합계 assert.
- 검수: figlib 0건 → check_figs 0건 → preview PNG·흑백을 직접 열어 확인.
```

7. 킷 예제로 동작 확인: 빈 폴더에서 `python3 ~/mdfile/biofig_kit/example_figs.py` → `fig/ex_cell.svg`(세포 단면+포함 검사), `ex_forest.svg`(숲그림), `ex_membrane.svg`(막·수용체·성분 표지).
