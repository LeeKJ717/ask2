## 0. 한 쪽 요약

**구성**
1. **원자에서 시작한다.** 모든 과학은 원자 개념·원자의 특성을 먼저 세우고, 거기서 파생되는 개념을 차례로 잇는다. 교과서 목차는 참고만 한다.
2. **논리적 의존 순서**: 원자 → 원자의 재료(빅뱅·기본 입자) → 원자의 전기적 성질(전하: 양성자 +, 전자 −) → 전기력·전기장 → 움직이는 전하(전류) → 자기장 → 전자기력(플레밍 왼손)·전자기 유도(오른손) → 전자기파. 그다음 **원자의 질량 → 관성 → 모든 원자가 서로 당김(중력)** → 접촉력·마찰력(= 원자 사이 전기력) → 운동 법칙 → 운동량 → 에너지 → 파동·빛 → 반도체·원자핵 에너지.
3. **"그런 것이 있다"를 실험과 과학사로 먼저 보인다.** 전기장은 쿨롱의 저울과 패러데이의 역선, 자기장은 외르스테드의 나침반으로. 정의·공식은 그 뒤에.
4. **과학자의 일생 1~2쪽**(생애 연표 그림 포함)을 그 발견이 나오는 장에 넣는다.
5. **문제에도, 풀이(해설)에도 그림.** 문제 그림은 상황, 풀이 그림은 풀이의 핵심 한 단계(힘 분해, 오른손 방향, 넓이=거리)를 보여 준다.

**그림**
6. 좌표 SVG 직접 생성. 폭 800 = 인쇄 120mm, **글자 22단위(9.4pt) 이상**.
7. **방향과 모양은 손으로 찍지 않고 계산한다.** 전기력선은 쿨롱 법칙 수치 적분, 자기력선은 자극 모형·오른손 법칙, 힘 방향은 벡터곱 F = qv×B, F = IL×B. 힘 평형 그림은 `assert`로 합력 0을 확인한다.
8. 검사: 글자 겹침·넘침·가림·크기 + **[물리판 추가] 선이 글자를 관통**(힘 화살표·역선·도선·축). 흰 테두리 글자(`halo=True`)만 예외.
9. PNG(컬러·흑백)를 **총괄이 직접** 연다. 자동 검사는 과학 방향 오류를 못 잡는다(화학 편: 음극선 휘는 방향 오류, 생명 편: 화살표 방향 오류).

## 1. 책 구성 원칙

### 1-1 원자 먼저, 파생 개념은 뒤에
| 나중 개념 | 앞에 반드시 있어야 할 개념 |
|---|---|
| 전기장 | 전하(양성자 +, 전자 −) — 전하는 원자의 성질 |
| 자기장 | 전류 = 움직이는 전하 (외르스테드) |
| 자석 | 원자 속 전자의 운동(궤도·스핀)이 만드는 작은 자기장, 자기 구역 정렬 |
| 플레밍 왼손 법칙 | 자기장 + 움직이는 전하가 받는 힘(로런츠 힘) |
| 플레밍 오른손(전자기 유도) | 자기장 속에서 도선 속 전자를 움직이면 전자가 힘을 받는다 |
| 전자기파 | 변하는 전기장 ⇄ 변하는 자기장, **가속하는 전하**가 전자기파를 낸다 |
| 관성 | 원자의 질량은 거의 원자핵(양성자·중성자)에 있다 → 물체의 질량 = 핵자의 양 |
| 중력 | 모든 원자(질량)는 서로 당긴다. 원자는 전기적으로 중성이라 큰 규모에서는 전기력이 상쇄되고 중력이 남는다 |
| 수직항력·탄성력·마찰력 | 표면 원자의 전자끼리 밀어내는 전기력, 맞닿은 원자 사이 결합 |
| 반도체·태양 전지 | 원자 속 전자의 에너지(에너지띠), 원자 배열(결정) |
| 원자핵 에너지 | 강한 힘, 질량–에너지(E = mc²) |

**정확성 주의**: "전하가 가속운동을 하면 자기장이 생긴다"는 부정확하다. **움직이는 전하(전류)는 속력이 일정해도 자기장을 만들고**, **가속하는 전하는 전자기파(빛)를 낸다**. 책에서는 이 둘을 구분해서 쓴다.

설계서에는 장마다 **"앞선 개념 ← 몇 장"** 한 줄을 적어, 뒤 장 개념이 앞에 나오지 않는지 확인한다.

### 1-2 존재를 먼저 보인다 (실험·과학사)
- 새 장(場)이나 힘은 **관찰 → 수수께끼 → 실험 → 개념 → 수식** 순서. 예) 나침반이 도선 옆에서 돈다(1820) → "전류 둘레에 무엇이 있다" → 쇳가루 무늬 → 자기장 → B의 방향 약속 → 오른손 법칙.
- 과학사 사실(누가·언제·무슨 장치)은 반드시 인용을 단다. 연도가 나오는 대사에는 인용이 따라온다(검사기).

### 1-3 과학자 일생 상자 `<<LIFE>>`
- 1~2쪽(1,300~2,200자). **생애 연표 그림**(`phys.lifeline`) 1점 + 이야기: 어린 시절·전환점·핵심 실험·실패와 논쟁·남긴 것. 평전(K 문헌)과 원전 논문을 인용.
- 사람을 우상화하지 않는다: 틀린 생각·경쟁·운도 적는다(예: 밀리컨 데이터 선별 논쟁, 톰슨의 건포도 푸딩 모형).

### 1-4 문제와 풀이의 그림
- 문제 N-1(선택형), N-2(서술·계산형). 상황이 있는 문제는 **문제 그림**(문제 상자 안 `<<FIG>>`).
- 풀이 대화 끝(또는 중간)에 **풀이 그림**: 힘 분해·방향 결정(손가락)·그래프 넓이·전기력선 비교처럼 "이 한 장이면 풀린다"는 것.
- 캡션: "문제 7-1의 그림"/"풀이 그림: …". 문제 그림에는 답이 드러나지 않게(정답 화살표 금지).

## 4. 방향은 계산한다 (물리 그림의 제1원칙)

1. **좌표 약속**: 물리 좌표 x 오른쪽, y 위, **z 종이 밖(보는 사람 쪽)**. ⊙ = +z, ⊗ = −z. SVG는 y가 아래이므로 `Frame`/`Proj`로만 바꾼다.
2. **힘 방향**: `F = Ph.wire_force(I, B)` → `assert F == (0, 1, 0)`처럼 **기대 방향을 적어 두고** 그린다. 손으로 화살표를 찍지 않는다.
3. **평형**: 모든 힘 벡터를 더해 `assert |합| < 1e-6`. (예제를 만들며 빗면 마찰력을 **아래쪽으로 잘못 그렸고 assert가 잡았다** — 사람 눈엔 그럴듯해 보였다.)
4. **역선**: 전기력선·자기력선은 수치 적분으로만. 눈대중 곡선 금지. 선 개수는 전하량에 비례.
5. **전류 방향** = 양전하가 가는 방향(전지 + 극 → 바깥 도선 → − 극). 전자는 반대로 간다 — 전자 흐름을 그릴 땐 BLUE 점과 "전자의 이동" 라벨을 따로.
6. **나침반·쇳가루**는 그 자리의 계산된 B 방향으로 돌린다.
7. **그래프 수치**는 식으로 그리고, 본문·풀이의 숫자와 같은 식에서 뽑는다(v–t 넓이 = 풀이의 답).

## 6. 그림 레시피
| 대상 | 방법 |
|---|---|
| **점전하 전기력선** | `field_lines([(x,y,q),…], box, per_unit=10~12)` — (가)(나) 두 패널 비교는 폭 400씩 |
| **평행판 전기장** | `plates()` + 사이에 전하 입자·힘 화살표(`force`) |
| **막대자석 자기장** | 자석 먼저 그려 윤곽 얻기 → `magnet_field_lines(..., avoid=윤곽)` → 자석 다시 그리기 → 나침반 |
| **직선 전류 자기장** | 평면: `wire_B_circles`; 입체: `Proj` + `wire3d_B` + 오른손(엄지=I) |
| **원형·솔레노이드** | `solenoid(pr)` + 안쪽은 곧은 역선, 바깥은 막대자석처럼 |
| **자기장 속 도선·전하** | ⊗/⊙ 격자 배경 + 도선 + `force(방향=wire_force)` + 옆에 `hand_rule` |
| **전동기** | 사각 코일(Proj) 두 변의 힘이 반대 → 회전, 정류자 |
| **발전기·유도** | 코일 속으로 드나드는 자석, 검류계 바늘 방향, 렌츠 법칙(유도 전류의 자기장이 변화를 방해) |
| **실험 장치** | 음극선관(`plates`+전자 경로 포물선 — 경로 방향은 전기력 = qE로 계산), 비틀림 저울, 기름방울(두 판 사이 방울에 qE와 mg), 금박 산란(알파 입자 궤적은 쿨롱 척력 수치 적분으로!) |
| **자유 물체도** | 물체 중심(또는 접촉면)에서 `force`, 모든 힘 합 assert, 빗면은 `incline().on()` |
| **운동 그래프** | `Axes` + `curve`/`area`/`guide`, s–t·v–t·a–t 세로로 나란히 |
| **포물선 운동** | 같은 시간 간격 점(스트로보) + 수평·수직 성분 점선 — 수평 등간격, 수직 1:3:5 |
| **충돌** | 전·후 두 줄, 운동량 화살표 길이 ∝ mv, 합 assert |
| **에너지 막대** | 운동·위치·열 에너지 쌓은 막대가 높이마다 같은 총합(assert) |
| **파동** | `wave` + `dim`(파장·진폭), 횡파/종파(촘촘·성김 점) |
| **스펙트럼** | `spectrum('continuous'|'emission'|'absorption', lines=[…nm])` — 수소 410·434·486·656 nm |
| **원자·입자** | `nucleus`, `bohr_atom`(모식도 명시), 쿼크 uud/udd |
| **에너지띠(반도체)** | 가로 띠 상자 2개 + 간격(띠틈) 치수선, 전자(BLUE 점)·양공(빈 원) |

## 7. 흔한 과학 오류 (눈 검수 목록)
- 전기력선이 서로 교차하거나 전하 없는 곳에서 시작/끝남 → 수치 적분이면 생기지 않는다.
- 자기력선이 자석 **밖에서 N→S**, 안에서 S→N(닫힌 곡선). 나침반 N극이 역선 방향.
- ⊙⊗ 헷갈림: ⊙ 나옴, ⊗ 들어감.
- 전자는 전류와 **반대 방향**으로 움직인다 — 음극선(전자)이 받는 힘은 F = (−e)v×B.
- 플레밍 **왼손 = 전동기(힘)**, **오른손 = 발전기(유도 전류)**. 엄지·검지·중지 = F·B·I (왼손), 운동·B·유도 전류(오른손).
- 수직항력은 항상 중력과 같지 않다(빗면, 엘리베이터). 작용–반작용 쌍은 **서로 다른 물체**에 작용.
- 던진 공의 꼭대기에서 속도 수평 성분은 0이 아니다; 가속도는 늘 아래로 g.
- 마찰력은 운동(또는 운동하려는) 방향의 **반대**.
- 변압기는 **교류**에서만. 송전 손실 P = I²R → 전압을 높여 전류를 줄인다.
- 광전 효과: 빛의 세기가 아니라 **진동수**가 문턱을 넘어야 전자가 나온다.

## 12. v3에서 더한 방법 — 과학자 초상·삶의 지도, 스펙트럼 방향, 최전선 나누기 (2026-09-30)
