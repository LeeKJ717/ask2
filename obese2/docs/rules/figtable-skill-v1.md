# 그림·표·그래프 작성 스킬 v1

> 과학과영성출판사 대중서 《산(酸)의 생리학》을 만들며 정리한 그림·표·그래프 작성 방법이다. 1장·2장 원고(사용자 확인: "그림·그래프 품질 좋아")에서 실제로 쓴 방식을 그대로 옮겼다. 다른 책에도 그대로 쓸 수 있다.
>
> 근거 파일: `acidbook/그림/01장·02장/make-figures.py`, `acidbook/tools/build-pdf.py`, `acidbook/tools/check-layout.py`, `acidbook/집필지침.md`

---

## 1. 다섯 가지 원칙

1. **데이터가 먼저다.** 그래프는 실제 측정값(논문·교과서·공식 자료)이나 공식으로 계산한 값으로만 그린다. 수치를 지어내지 않는다.
2. **데이터와 그림을 분리해 저장한다.** 숫자는 CSV로, 그리는 방법은 파이썬 스크립트로 둔다. 숫자가 바뀌면 스크립트만 다시 돌리면 된다(bookrule2 "원고를 파싱해 별도 저장" 규칙).
3. **정량 자료가 아닌 도식은 "개념도"라고 밝힌다.** 흐름도·시간축·구조도처럼 정확한 수치가 없는 그림은 그림 설명에 "개념도"라고 쓴다.
4. **그림마다 본문에 "숫자를 읽어 주는" 해석 문단을 붙인다.** 그림만 던져 놓지 않는다. 그림에서 무엇을 읽어야 하는지 구체적인 숫자로 짚어 준다.
5. **눈으로 확인한다.** 그림을 만든 뒤 PNG를 직접 열어 글자 겹침·잘림을 고치고, PDF로 조판한 뒤 쪽마다 다시 본다.

여섯 가지 색을 책 전체에서 같은 뜻으로 쓴다. 흑백판에서도 구분되도록 색마다 빗금(hatch)이나 표식, 선 모양을 함께 준다.

**표 3. 색 팔레트**

| 이름 | 색 코드 | 주로 쓰는 곳 | 흑백 구분 |
|---|---|---|---|
| BLUE | #2b6cb0 | 기본 계열, 혈액·물 | 빈 막대, 실선, 동그라미 |
| ORANGE | #dd6b20 | 두 번째 계열 | `//` 빗금, 네모 |
| GREEN | #2f855a | 정상·좋음·염기 | `..` 또는 실선, 마름모 |
| RED | #c53030 | 위험·산·강조 | `xx` 빗금, 파선, 세모 |
| PURPLE | #6b46c1 | 다섯째 계열 | `\\` 빗금, 점선 |
| GRAY | #718096 | 보조·참고선·설명 | `--` 빗금 |

### 위첨자·아래첨자 문제

맑은 고딕에는 ⁺ ⁻ ₂ ₃ 같은 글자가 없어서 그대로 쓰면 네모로 깨진다. 수식 표기로 바꿔 주는 함수 `fx()`를 모든 글자에 통과시킨다.

```python
def fx(s):
    """맑은 고딕에 없는 위첨자·아래첨자 부호를 수식 표기로 바꾼다."""
    return (s.replace("⁺", "$^{+}$").replace("⁻", "$^{-}$").replace("−", "-")
             .replace("₂", "$_{2}$").replace("₃", "$_{3}$").replace("₄", "$_{4}$"))
```

그림을 만든 뒤 경고 메시지에 `Glyph … missing`이 나오면 그 글자를 `fx()`에 더한다.

## 5. 스크립트 기본 틀

모든 장의 `make-figures.py`는 이 틀에서 시작한다.

```python
import csv, pathlib
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
from PIL import Image
HERE = pathlib.Path(__file__).parent
DATA = HERE / "data"
plt.rcParams.update({"font.family": "Malgun Gothic", "axes.unicode_minus": False,
                     "font.size": 10, "axes.spines.top": False, "axes.spines.right": False})
BLUE, ORANGE, GREEN, RED, PURPLE, GRAY = "#2b6cb0", "#dd6b20", "#2f855a", "#c53030", "#6b46c1", "#718096"
def rows(name):                       # CSV 읽기
    with open(DATA / name, encoding="utf-8") as f:
        return list(csv.DictReader(f))
def save(fig, name):                  # 컬러판과 흑백판을 함께 저장
    path = HERE / f"{name}.png"
    fig.savefig(path, dpi=300, bbox_inches="tight", facecolor="white")
    plt.close(fig)
    Image.open(path).convert("L").save(HERE / f"{name}-흑백.png")
```

그림 하나는 함수 하나로 만들고, 맨 아래에서 본문 순서대로 부른다. 실행은 `python -X utf8 그림/NN장/make-figures.py`.

## 6. 그래프 유형별 요령

### 6-1. 공식으로 계산한 곡선

공식이 있으면 수치를 손으로 옮기지 말고 계산한다. 계산이 곧 출처이므로 틀릴 일이 없다.

```python
ph = np.linspace(0, 10, 400)
for name, pka in [("젖산", 3.86), ("초산", 4.76), ("히스티딘", 6.0)]:
    frac = 100 / (1 + 10 ** (pka - ph))          # 헨더슨-하셀바흐
    ax.plot(ph, frac, label=f"{name} (pKa {pka})", marker="o", markevery=50)
ax.axvspan(1.0, 3.0, color="#fed7d7")            # 위의 pH 범위를 배경 띠로
```

![그림 A-1](acidbook/그림/01장/그림1-6.png)

**그림 A-1. 계산한 곡선의 예 — 헨더슨-하셀바흐 곡선(acidbook 그림 1-6).** 각 산의 pKa만 넣어 계산했다. 몸의 구역(위·대장·혈액)을 배경 띠로 깔아 "같은 산이 어디서 어떤 모습인가"를 한눈에 읽게 했다. 곡선마다 선 모양과 표식을 달리해 흑백판에서도 구분된다.

본문에는 이 그림을 이렇게 읽어 준다. "초산의 pKa는 4.76이다. pH 2인 위 속에서는 99.8%가 중성 분자이고, pH 7.4인 혈액에서는 99.8%가 이온이다." 그림 한 장에서 숫자 두 개를 꺼내 보여 주는 것이 해석 문단의 기본이다.

### 6-2. 자릿수가 크게 다른 양 — 로그 눈금

이산화탄소 2만 mmol과 비휘발성 산 50 mmol을 보통 눈금에 그리면 작은 막대가 보이지 않는다. `ax.set_xscale("log")`로 바꾸고, 그림 설명에 반드시 "가로축은 로그 눈금으로, 한 칸이 10배다"라고 적는다. 막대 끝에 실제 숫자를 써 준다.

### 6-3. 정렬한 가로 막대 — 항목 비교

```python
vals.sort(key=lambda v: v[1])                      # 값 순서로 정렬
cols = [RED if v > 0.5 else (GREEN if v < -0.5 else GRAY) for v in nums]
hats = ["xx" if v > 0.5 else ("" if v < -0.5 else "..") for v in nums]
bars = ax.barh(names, nums, color=cols, hatch=hats, edgecolor="white")
for b, v in zip(bars, nums):                       # 막대 끝에 값 표시
    ax.text(v + (0.4 if v >= 0 else -0.4), b.get_y() + b.get_height() / 2, f"{v:+.1f}",
            va="center", ha="left" if v >= 0 else "right", fontsize=8.5)
ax.axvline(0, color="black", lw=0.8)
```

계산에 쓴 원자료(영양 성분)와 계산 결과를 모두 CSV로 남긴다(`식품영양.csv`, `PRAL계산값.csv`).

![그림 A-2](acidbook/그림/02장/그림2-5.png)

**그림 A-2. 정렬한 가로 막대의 예 — 식품별 PRAL(acidbook 그림 2-5).** 양수(산을 남김)는 붉은 빗금, 음수(염기를 남김)는 녹색, 0 근처는 회색 점무늬로 칠했다. 값 순서로 정렬해 위에서 아래로 읽으면 순위가 보인다. 근삿값이라는 점을 그림 설명에 밝혔다.

### 6-4. 지도형 그래프 — 두 변수와 제3의 변수

세 변수가 한 식으로 묶여 있으면(pH, 중탄산, PaCO₂) 두 축을 고르고 세 번째 변수가 일정한 선(등압선)을 여러 개 그린다. 정상 범위는 반투명 상자로, 변화 방향은 화살표로 표시한다. 선 끝에 값을 붙이고, 기준선(정상 40 mmHg)만 굵게 한다.

![그림 A-3](acidbook/그림/02장/그림2-4.png)

**그림 A-3. 지도형 그래프의 예 — 산·염기 지도(acidbook 그림 2-4).** 헨더슨-하셀바흐 식으로 PaCO₂ 20~80 mmHg의 등압선을 계산했다. 네 가지 산·염기 장애가 정상에서 움직이는 방향을 색과 화살표로 보였다.

### 6-5. 연구 결과 비교 — 막대와 오차 막대

논문 초록에 보고된 평균과 표준편차만 쓴다. 오차 막대가 무엇인지(표준편차인지 신뢰구간인지) 그림 안이나 설명에 적는다. 값 글자는 막대나 오차 막대와 겹치지 않게 막대 옆에 둔다.

### 6-6. 임상 공식 — 직선, 허용 범위 띠, 사례 점

윈터스 식(예상 PaCO₂ = 1.5 × HCO₃⁻ + 8 ± 2)처럼 범위가 있는 공식은 `fill_between`으로 띠를 깔고, 가상의 환자 몇 명을 점으로 찍어 "범위 안·위·아래"가 각각 무엇을 뜻하는지 화살표 설명으로 단다. 본문에는 같은 환자로 "응급실에서 동맥혈 가스 읽기" 같은 상자를 붙인다.

### 6-7. 도식(개념도) — 상자와 화살표

```python
from matplotlib.patches import FancyArrowPatch, FancyBboxPatch
def box(ax, x, y, w, h, text, fc, tc="white", fs=9.5):
    ax.add_patch(FancyBboxPatch((x, y), w, h, boxstyle="round,pad=0.04", fc=fc, ec="black", lw=0.6))
    ax.text(x + w / 2, y + h / 2, text, ha="center", va="center", color=tc, fontsize=fs, fontweight="bold")
def arrow(ax, a, b, lw=1.5, color="black"):
    ax.add_patch(FancyArrowPatch(a, b, arrowstyle="-|>", mutation_scale=14, lw=lw, color=color))
```

- 좌표계를 `ax.set_xlim(0, 10); ax.set_ylim(0, 6); ax.axis("off")`로 고정하고 그 안에 배치한다.
- 양이 큰 흐름은 화살표를 굵게(`lw=7`) 해 크기를 느끼게 한다.
- 화살표 설명 글자는 상자와 상자 사이 좁은 틈에 두지 말고 화살표 위·아래의 빈 줄에 둔다.
- 정량 자료가 아니면 그림 설명에 "개념도"라고 쓴다.

### 6-8. 분자 구조

구조식은 화학적으로 정확해야 한다. 원자 사이의 연결 순서를 반드시 확인한다. 1장에서 히스티딘 고리를 처음 그렸을 때 두 질소가 모두 곁사슬 탄소에 붙어 있는 실수가 있었다. 바른 순서는 Cγ–Nδ1–Cε1–Nε2–Cδ2다. 복잡한 분자는 RDKit(`python -m pip install rdkit`)으로 그려 정확성을 확보한다.

## 7. 겹침과 잘림 고치기

그림을 만든 뒤 PNG를 열어 다음을 확인한다.

**표 4. 자주 생기는 문제와 해결법**

| 문제 | 원인 | 해결 |
|---|---|---|
| 글자가 네모로 깨짐 | 맑은 고딕에 없는 글리프 | `fx()`로 수식 표기 |
| 좁은 막대 안의 글자가 넘침 | 값이 작은 칸 | 일정 값(예: 10%) 미만은 막대 밖에 화살표 설명으로 |
| 범례가 곡선을 가림 | 기본 위치 | `loc`와 `bbox_to_anchor`로 빈 곳에, 흰 바탕 상자 |
| 설명 화살표 글자가 선과 겹침 | 글자 위치 | `xytext`를 곡선 반대편으로 |
| 왼쪽 그림이 오른쪽 그래프를 침범 | `add_axes` 영역이 겹침 | 두 영역의 가로 범위를 다시 나눔 |
| 상자 안 글자가 넘침 | 상자가 좁음 | 상자 폭을 같게 하고 글자 위치·크기 조정 |
| B5에 넣으니 글자가 작음 | 그림이 너무 큼 | 폭 6.4인치 이하로, 글자 8.5 pt 이상 |

여러 그림을 한 장에 모아 축소판(접촉 인화지)으로 보면 빠짐없이 확인할 수 있다.

```python
from PIL import Image
ims = [Image.open(f"그림/02장/그림2-{i}.png") for i in range(1, 7)]
for im in ims: im.thumbnail((620, 420))
```

## 8. 그림 설명(캡션)과 해석 문단

### 원고 표기

조판 스크립트가 아래 형식을 알아보고 그림과 설명을 한 쪽에 묶는다. 이미지 줄, 빈 줄, `**그림`으로 시작하는 설명 문단 순서를 지킨다.

```
![그림 2-5](../그림/02장/그림2-5.png)
(빈 줄)
**그림 2-5. 제목.** 무엇을 그렸는지. 어떻게 읽는지. 단위·눈금. 자료: 출처.
```

### 설명에 넣을 것

1. **제목**(굵게) — 무엇을 보여 주는 그림인지 한 줄로
2. **구성** — 축, 색, 빗금이 각각 무엇인지
3. **핵심 결과 한두 개** — 그림에서 가장 중요한 숫자
4. **눈금·단위·한계** — 로그 눈금, 근삿값, 개념도 여부
5. **자료** — 출처(논문, 교과서, "~의 식으로 계산")

### 본문 해석 문단

그림 바로 뒤나 앞에 "그림 2-5를 해석해 보자"처럼 시작하는 문단을 둔다. 그림에서 숫자를 두세 개 꺼내 읽어 주고, 그 숫자가 무엇을 뜻하는지, 의외의 점은 무엇인지(예: "사과는 시큼하지만 염기를 남긴다") 짚는다.

## 9. 표

- **열은 5~6개 이하.** B5 본문 폭에서 읽히는 한계다. 열이 많으면 표를 나눈다(1장의 "몸속 주요 산" 표를 무기산 표 1-1과 유기산 표 1-2로 나눔).
- 데이터는 `표/NN장/표N-M.csv`로도 저장한다.
- 표 바로 뒤에 `표의`로 시작하는 주석 한 줄을 단다(대략적인 값인지, 기준이 무엇인지).
- **원고 표기** — 제목 줄, 빈 줄, 표, 빈 줄, 주석 한 줄. 이 형식이어야 세 부분이 한 쪽에 묶여 두 쪽으로 갈라지지 않는다.

```
**표 2-1. 몸의 주요 완충계**
(빈 줄)
| 완충계 | 짝 | pKa | 주로 일하는 곳 | 특징 |
|---|---|---|---|---|
| 중탄산 완충계 | CO₂ / HCO₃⁻ | 6.1 | 혈장·간질액 | 가장 강력하다 |
(빈 줄)
표의 pKa는 체온 근처의 대략적인 값이다.
```

- 표 뒤에도 그림처럼 "표에서 읽어 낼 세 가지" 같은 해석 문단을 붙인다.

## 10. 조판과 점검

### PDF 빌드

```
python -X utf8 tools/build-pdf.py 원고/02장-v1.md
```

- 판형: B5(182 × 257 mm), **좌측 20% 여백**, 본문 10.5 pt·줄간격 1.8. 파일 이름이 `목차`로 시작하면 A4.
- **그림·표 묶기**: 그림+설명, 표 제목+표+주석이 한 쪽에 놓인다.
- **자동 배치**: 그림이나 표가 다음 쪽으로 밀려 앞쪽 아래가 15% 넘게 비면, 그 그림·표를 바로 뒤 문단과 자리를 바꿔 다시 조판한다. 이것을 최대 15번 되풀이해 빈 공간이 가장 적은 결과를 고른다. 원고 파일의 순서는 바뀌지 않는다.
- 모든 쪽 하단에 쪽번호가 들어간다.

### 빈 공간 점검

```
python -X utf8 tools/check-layout.py 원고/02장-v1.pdf
```

15% 넘게 빈 쪽과 그다음 쪽이 무엇으로 시작하는지 알려 준다. 수작업으로 그림을 옮기면 한 곳을 고칠 때 다른 곳이 비는 일이 반복된다. 그래서 자동 배치를 만들었다. 그래도 남는 빈 공간은 그림 높이를 줄이거나(예: `figsize`의 높이 4.0 → 3.3) 표를 관련 문단 뒤로 옮겨 해결한다.

### 쪽 눈으로 보기

PDF 전체를 축소판 한 장으로 렌더링해 훑어본다.

```python
import pymupdf, io
from PIL import Image
d = pymupdf.open("원고/02장-v1.pdf")
pages = [Image.open(io.BytesIO(d[i].get_pixmap(dpi=40).tobytes("png"))) for i in range(d.page_count)]
w, h = pages[0].size; cols = 5; rows = (len(pages) + cols - 1) // cols
sheet = Image.new("RGB", (w * cols, h * rows), "#ddd")
for k, im in enumerate(pages): sheet.paste(im, ((k % cols) * w, (k // cols) * h))
sheet.save("쪽검토.png")
```
